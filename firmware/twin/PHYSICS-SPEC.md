## 2. 模型定义（实现于 twin_api.c）

状态：p（汇流管表压 kPa）；端口阀开集 S；各阀 duty u。

每 tick（50ms，dt=0.05）：
```
P = p + 101.325（绝对压 kPa）→ 按 ANSI 单位换算 bar
V = V_m + |S|·V_p                       （L）
Q = 0
若 pump∧inlet：  Q += u_pump·C_pump·F(P, P_R)     F(x,y)=114.5·√(x(y−x))/√T   [sub-critical]
                                                        临界：x/y > 0.528 → 恒流支
若 pump∧vent(真空)：Q −= u_pump·C_pump·F(P_atm↔, P_min)   （对称，P<P_atm 时抽气）
若 vent∧¬pump：  Q −= C_vent·F_choked(P, P_atm)   （释放；P<P_atm 时反向回充）
dp = γ·(P)/V · Q · dt                    （γ=1.2）
端口阀 0→1 瞬间：p ← p·V_旧/V_新          （新通道为大气压，等温瞬时混合）
p 钳位 [−100, +100] kPa（XGZP6897D 量程饱和）
```

## 3. 参数表（标定计划）

| 参数 | 含义 | **实测值（实验校准）** | 校准依据 |
|------|------|----------------------|---------|
| P_R−P_atm | 泵充气滞止表压 | 61 kPa | FlowIO Small Pump Module 实测死点（thesis Table 2） |

## 4. 验证（更新 TEST-CASES §I）

- 充压曲线按 √ 压头形式拟合（非线性回归替代 v1 的渐近线性断言）
- 高压差段（>53 kPa 表压，P/P_atm>1.893 边界之上）识别 choked 恒流：释放初期降压速率近似恒定
- **容积耦合**：同 PWM 下开 1 口 vs 开 3 口充压，后者速率显著低（ΔV/V 断言）
- 开阀混合：密封 60 kPa 时开新端口 → 压力阶跃下降且按 V_m/(V_m+V_p) 可预测
- 真空/回充/微漏/量程饱和：沿用 v1 用例
- 自测程序 twin_selftest.c 期望值按 v2 重算
