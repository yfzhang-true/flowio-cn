## 2. 模型定义（实现于 twin_api.c）

状态：p（汇流管表压 kPa）；端口阀开集 S；各阀 duty u。

每 tick（50ms，dt=0.05）：
```
P = p + 101.325（绝对压 kPa）→ 按 ANSI 单位换算 bar
V = V_m + |S|·V_p                       （L）
Q = 0
若 pump∧inlet：  Q += u_pump·C_pump·F(P, P_R)     F(x,y)=114.5·√(x(y−x))/√T   [sub-critical]
                                                        临界：x/y > 0.528 → 恒流支
若 pump∧vent(真空)：Q −= u_pump·C_pump·F(P_atm↔, P_min)   （对称，P<P_atm 时抽气）
若 vent∧¬pump：  Q −= C_vent·F_choked(P, P_atm)   （释放；P<P_atm 时反向回充）
dp = γ·(P)/V · Q · dt                    （γ=1.2）
端口阀 0→1 瞬间：p ← p·V_旧/V_新          （新通道为大气压，等温瞬时混合）
p 钳位 [−100, +100] kPa（XGZP6897D 量程饱和）
```

## 物理 v2.1：多节点端口模型（2026-09-22，用户 bug 报告触发）

**触发**：用户实测发现 G 闭环后汇流管缓降而"端口1压力"纹丝不动。

**根因**：物理层只有汇流管单一气压节点；"端口压力"是 GUI 前端变量（阀开拷贝、阀关冻结），无仿真状态。更深层：端口泄漏被无条件作用于汇流管节点——物理上阀关后端口侧泄漏对汇流管传感器不可见，v3 ML 训练数据因此含物理上不成立的签名。

**v2.1 模型**：
1. 每端口独立节点 `s_port_p[5]`：关阀瞬间快照汇流管压力，此后独立演化（自身密封微漏 1%/s + 端口泄漏孔口流）；开阀时与汇流管同节点
2. 开阀混合的端口初压用端口节点真值（原假设大气压）；关阀快照 `s_prev_ports` 检测
3. 端口泄漏（idx 0-4）移至端口侧：阀开对汇流管可见、阀关不可见（`ports_p` 可见）
4. 基线微漏条件修正：泵侧密封即适用（含 H 诊断保压的端口全通态），不再要求端口全关
5. 新增 CLI `H <ports>`（pn_hold_open）：泵侧密封+端口保持通 = 泄漏诊断的标准工况

**导出**：`pn_twin_port_pressure(idx)` → `/api/state.ports_p` → GUI 端口卡片（前端冻结 hack 删除）。

**ML v5 连锁修正**：工况改 H 语义；发现并修复采样率声明错误（每 tick 一点 = 20Hz，原标 50Hz 致斜率虚高 2.5 倍）；标签改物理可观测 Δ 分级（宪法第 12 条）；类平衡采样。终值：acc 95.73%、normal R 98.6%、major R 95.3%（零漏报为 normal）、18KB。
