## 0. 如何运行

```bash
cd firmware/twin
bash run_tests.sh          # 一键：自起 8017 隔离实例 → 冒烟+接口+单元+功能 → 自动清理
```

- **测试隔离**：测试默认在 **8017 端口自起独立服务实例**，与浏览器正在使用的 8000 互不干扰（否则双方命令会串扰，产生假失败）
- 单独运行：`bash test_api.sh`（自起实例）· `node test_gui.js` / `node test_e2e.js`（需 8017 已就绪或设 `TWIN_URL`）
- 环境变量：`TWIN_PYTHON`（python 路径，默认 conda paper20-cu128）· `TWIN_URL`（指向已运行服务）· `TWIN_CHROME`（Chromium 路径）
- 单元/功能测试另需 playwright-core：`NODE_PATH=<其 node_modules 父目录> bash run_tests.sh`

## 1. 接口测试用例（36 项 · test_api.sh）

前置：隔离实例已启动，状态从零开始（脚本检测到超压锁存会自动 `POST /api/reset` 虚拟断电自愈）。

### A. 协议契约（API-01~09）

| ID | 用例 | 预期 |
|----|------|------|
| API-01~06 | GET /api/state 字段完整性 | 含 state / valves / pump / sensors / cl / err 六字段 |

| ID | 用例 | 预期 |
|----|------|------|
| API-10 | 状态字 | 0x02A7（泵 bit7 + 进气 bit5 + 端口1-3 bit0-2 + 传感在线 bit9） |

### C. 保压 `S 7`（API-17~19）
