## 0. 如何运行

```bash
cd firmware/twin
bash run_tests.sh          # 一键：自起 8017 隔离实例 → 冒烟+接口+单元+功能 → 自动清理
```

- **测试隔离**：run_tests.sh 在 8017 端口自起独立实例（含残留实例清场 + 物理签名验证，防 Windows 双绑定幽灵），与浏览器正在使用的 8000 互不干扰
- 单独运行：`bash test_api.sh`（自起实例）· `node test_gui.js` / `node test_e2e.js`（需 8017 就绪或设 `TWIN_URL`）
- 环境变量：`TWIN_PYTHON` · `TWIN_URL` · `TWIN_CHROME`；单元/功能另需 playwright-core（`NODE_PATH` 指向其 node_modules）

## 0.5 孪生物理模型（本轮被测对象）

v1.1 起物理按一阶气动规律实现（twin_api.c，参数为 P0 标定占位）：

| 规律 | 模型 | 占位参数 |
|------|------|---------|
| 泵充压 | dp/dt = K·(duty/255)·(1 − p/Pmax)，渐近死点 | K=30kPa/s，Pmax=65kPa（规格 50–70 取中） |
| 泵抽真空 | 对称模型，渐近极限真空 | Pmin=−45kPa |
| 被动排气 | 指数衰减 p∝e^(−t/τ)（压差驱动，负压自然回充） | τ=1.6s |
| 密封微漏 | 漏率 ∝ 压差 | 1%/s |
| 传感器 | XGZP6897D 量程 ±100kPa，注入与演化均按量程饱和 | ±100kPa |

**⚠ 重要发现（固件设计缺陷，待用户决策）**：超压保护阈值 120kPa 高于传感器量程上限 100kPa——真机与孪生上该保护**永远无法触发**（盲区）。孪生如实建模（注入 125 只会饱和显示 100、不触发保护）。建议将阈值降到量程内（如 90kPa），等你拍板后一并改固件与孪生。
