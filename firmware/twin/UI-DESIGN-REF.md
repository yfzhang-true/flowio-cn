## 1. PneUI 的可借鉴设计原则

| PneUI 原则 | 现状 | 改进建议（P2，审查后实施） |
|-----------|------|--------------------------|
| **压力→形变连续映射**（bending 随气压连续加深为 curling） | 气球仅有缩放 | 端口图形按压力连续演化：小→胀→颈缩三态连续插值；或提供"弯曲执行器"端口类型（弧线弯曲角随压力） |
| 形变方向由材料设计决定（各向异性） | 不适用 | 端口类型档案：气球/弯曲臂/波纹管——影响 SVG 图形与 Scheduler 语义（教学场景有用） |
| 交互词汇自明（stretch/bend/embrace/stroke/squeeze） | 充/保/释/抽 | 保持现行中文动词（已自明）；卡片可加执行器类型图标 |
| 亚秒级响应目标 | 200ms 轮询 ✓ | 已达标 |

## 2. FlowIO 官方 GUI 特性对照

| 官方特性 | 现状 | 建议 |
|---------|------|------|
| Web GUI 免安装（Web Bluetooth） | 本地孪生 HTTP | P2：真机接入后评估 Web Serial/BLE 直连 |
| **配置自适应**（换泵配置 GUI 一键适配，Fig.6） | 固定 P0 单泵 | P1 双泵（串/并联）时：配置档案切换 → SVG 双泵/汇流拓扑与规格包线随之变化 |
| 动作按钮 + PWM 滑块 + 多口同时动作 | ✓ 均已具备 | — |
| 压力单位（psi/kPa） | 仅 kPa | 加单位切换（官方规格以 psi 标注，±psi↔kPa 一键） |
| 规格包线 −26~+30 psi | 无显示 | 曲线图叠加传感器量程(±100kPa)与泵包线着色带（安全视觉边界） |
| 分时单传感器（Sensors++ 为每口独立） | S0/S1 语义已注明 | P1：多传感器面板 |
