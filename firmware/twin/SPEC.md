# FlowIO-CN P0 · 数字孪生前端 SPEC v1.0

> 状态：待用户审查

## 1. 目标

一个**单文件 HTML 页面**（proto3d.html），提供 FlowIO P0 虚拟孪生控制台，通过 `/api/state`（GET 轮询）和 `/api/cmd`（POST 命令）与 `pn_twin.dll` 通信。

## 2. 页面布局

```
┌─────────────────────────────────────────────────┐
│ 顶栏: 品牌 | 状态字 | 闭环状态 | 错误 | 时钟     │
├──────────┬──────────────────────────┬───────────┤
│ 左栏     │ 中栏                     │ 右栏      │
│ 端口控制 │ 动画气路示意图            │ ECharts  │
│ 卡片 ×5  │ (SVG: 泵+阀+汇流管)      │ 压力曲线  │
│          │                          │           │
├──────────┴──────────────────────────┴───────────┤
│ 底部: 任务序列编辑器 | 执行日志 | 运行/停止按钮   │
└─────────────────────────────────────────────────┘
```

### 2.1 顶栏
| 元素 | 更新频率 |
|------|---------|
| state=0xXXXX | 400ms |
| 闭环状态 IDLE/RUNNING/DONE/TIMEOUT/ERR | 400ms |
| 错误指示（绿点/红点） | 400ms |
| 时钟（秒，模拟时钟） | 400ms |

### 2.2 左栏：端口控制卡片 ×5
每张卡片包含：
- 端口名（端口1 ~ 端口5）
- 当前压力值（大字，kPa）
- 阀状态标签（阀开/阀关·密封）
- 4 按钮：充 / 保 / 释 / 抽
- 端口 4/5 灰显 + "备用"标签

### 2.3 中栏：动画气路示意图（SVG，对标 FlowIO 官方 Web GUI）

**设计基准**：FlowIO 官方 softrobotics.io/gui 的 Config/Control 面板（用户已确认截图为标准）。

**SVG 元素清单**：

| 元素 | SVG 实现 | 状态映射 | 动画 |
|------|---------|---------|------|
| 汇流管腔体 | 圆角矩形，浅蓝色底 (#dde9f3)，蓝色边框 | 始终显示 | 无 |
| 阀活塞 ×7 | 深色圆角矩形 + 弹簧锯齿线，在腔体内垂直排列 | ON=绿色+下压位 / OFF=灰色+弹起位 | fill + translateY 过渡 0.2s |
| 端口接口 ×5 | 活塞上方的短管伸出腔体顶部 | 始终显示 | 无 |
| 泵 | 圆形叶轮（3 叶片） | ON=旋转动画 / OFF=静止 | CSS rotate 无限循环 |
| 流向箭头 | 红色箭头对，充气时指向汇流管，排气时指向大气 | 充气=显示→ / 排气=显示← / 停止=隐藏 | opacity 切换 |
| 压力表 | 汇流管右侧小圆表，指针+数字 | 实时压力值 | 指针角度平滑过渡 |
| 大气标记 | 文字 "大气" | 始终显示 | 无 |

**阀活塞布局（7 个）**：


**交互映射**：

| 用户操作 | 阀活塞动画 | 泵叶轮 | 流向箭头 |

## 3. 通信协议

### 3.1 轮询
- `GET /api/state` → JSON `{state, valves[], pump, sensors[], cl, err}`
- 频率：400ms

### 3.2 命令
- `POST /api/cmd` → body 为 CLI 命令字符串（如 `I 7 255`）
- 服务端转发至 pn_twin.dll → pn_cli_process_line → pn_core

### 3.3 仿真注入
- `POST /api/sim` → body 为 `<idx> <kPa>` → 设置 mock 传感器读数

## 4. 数据流

```
pn_twin.dll (pn_core 逻辑层)
    ↕ ctypes (server.py)
Python HTTP 服务 (127.0.0.1:8000)
    ↕ HTTP GET /api/state + POST /api/cmd
浏览器前端 (proto3d.html)
```

## 6. 约束

- 单文件 HTML，无构建步骤，无外部依赖（ECharts 通过 /lib/ 路由本地服务）
- 逻辑层全部在 pn_core（C 代码，DLL），前端只做展示和控制
- 前端不直接控制硬件——所有操作通过 /api/cmd → pn_core → DLL → 真机

## 8. v1.1 修订（2026-09-21 用户审查反馈）

1. **端口 4/5 启用**：取消 §2.2 的"灰显 + 备用标签"——P0 硬件 7 阀全在，5 端口全部可用。
2. **端口卡片压力语义**：不再绑定 S1（其不随物理演化，导致恒显 0.0）；改为"端口压力"= 阀开时跟随汇流管压力（S0），阀关时密封保持——与气球动画同源。
3. **S0/S1 命名人性化**：UI 统一显示"汇流管压力 (S0)""端口侧探头 S1（需注入）"，SVG 压力表标注放大且不再被图形遮挡。
4. **维护按钮自说明**（F 自检 / T 状态字 / L 阀节能 / X 闭环复位）：悬停提示完整功能说明 + 面板内一行微帮助。
5. **超压锁存恢复**：新增 `POST /api/reset`（虚拟断电）与错误横幅，保留"锁存仅断电可清"的安全语义。
6. **测试隔离**：测试自起 8017 独立实例，与用户操作中的 8000 互不干扰（`run_tests.sh` 一键）。

## 9. v1.2 修订（2026-09-21 孪生物理真实性要求）

物理模型从"恒速简化"升级为**一阶气动规律**（禁止硬编码轨迹误导用户）：
充压/抽真空速率 ∝ duty 且随压差渐近泵死点（65kPa）/极限真空（−45kPa）；
被动排气与微漏为压差驱动指数过程（负压自然回充）；传感器按 ±100kPa 量程饱和。
标定参数为占位值，到货实测修正。**同时发现固件缺陷：超压阈值 120>量程 100=保护盲区，待用户决策。**
