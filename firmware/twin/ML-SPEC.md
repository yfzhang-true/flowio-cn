## 0. 固件端部署记录（2026-09-23，用户质询"为什么不用上模型"触发）

**推理已进固件**（不再只在 PC 管线）：`components/pn_ml` 纯 C int8 推理器（零依赖，
host DLL / ESP32 / QEMU 三端同码），权重由 `ml_export_c.py` 从 int8 tflite 导出
（6299 参数，重训后重跑导出即可换模型）。

- **采样**：`pn_ml_tick()` 挂控制节拍（孪生 50ms/真机 10ms 任务，内部 ≥45ms 节流 20Hz），
  传感器#0 → 80 点环形缓冲（4s 窗口）；CLI `L` / `GET /api/leakdetect` 立即推理；
- **数值一致性**：C 推理器 vs TFLite Interpreter 21/21 对齐（max|Δp|≤0.011，
  `ml_conformance.c` 每次构建自动跑）——手写推理器不是"差不多"，是逐样本对齐；
- 途中两坑入档：① Interpreter 的 `tensor_details` 对常量权重 quantization 恒 (0,0)
  → 必须 flatbuffer schema 直解（`schema_py_generated`）；② CONV/FC 权重为
  **per-channel 量化**（dim=0），requant 乘子 m[oc]=s_in·s_w[oc]/s_out；
- **QEMU 整固件**：L 命令路由+采样器故障路径 9/9 冒烟过（QEMU 无 I2C 传感器模型→样本恒 0
  属环境限制，推理数值由 host 一致性+自测覆盖）；idf 编译过；
- **GUI 泄漏检测实验室**：注入（7 部位×k 滑杆）+ 立即检测 + 三色徽章（绿/黄/红）+
  样本进度条（state.ml 字段）；e2e 全流程用例 ×4；
- **最终模型**（class_weight {0:1.3} 调优后）：int8 acc 95.69% · normal R 95.9% ·
  minor R 92.1% · major R 98.7% · **normal↔major 双向零漏报** · 18KB；
- 仍待到货：真机传感器数据上的迁移学习（Task 6/7）、Edge Impulse 平台上传（CSV 已备）。

## 1. 双阶段策略

### 阶段 1：仿真预训练（现在，无硬件）

| 目的 | 说明 |
|------|------|
| 管线验证 | 代码端到端跑通（数据→特征→训练→评估→导出），到货后无需改代码 |
| 架构搜索 | 确定 1D CNN 层数/核数/dropout 是否够用（省真机训练时间） |
| 预训练权重 | 学会基本压力动态模式（充气斜率/保压微漏/释放骤降），真机微调时**减少 10× 数据需求** |
| **明确不产出** | 可部署模型——纯仿真模型在真机上预计 <60% 准确率 |

### 阶段 2：真机迁移学习（到货后，1 天）

| 步骤 | 说明 |
|------|------|
| 数据采集 | 真机 50-100 条（正常/松管/堵口/不同端口），同管线 |
| 微调 | 加载预训练权重 → lr=1e-5 → 5 epochs（防灾难性遗忘） |
| 验收 | 真机 hold-out ≥90%（仿真模型作 baseline 对比） |

## 2. 域随机化（仿真→真机迁移的关键）

| 扰动源 | 范围 | 目的 |
|--------|------|------|
| PUMP_C | ±20% | 泵批次个体差异 |
| VENT_C | ±20% | 阀路流阻公差 |
| LEAK_C | ±30% | 泄漏孔形状不确定 |
| 传感器偏移 | ±2 kPa 恒定 | 校准误差 |
| 传感器漂移 | ±0.5 kPa/min 线性 | 温漂 |
| 采样抖动 | ±2ms 高斯 | 定时器不精确 |
| 额外噪声 | 1/f 噪声 + 白噪声混合 | 真实噪声谱（非纯高斯） |
| **采样率差异** | 95-105Hz（真机 10ms 任务 vs 孪生 50ms） | N16R8 固件 100Hz 实际采样 |
| **ADC 量化** | 15-bit 有效精度 | XGZP6897D 24-bit ADC 实际有效位 |

→ 预训练模型见过足够参数变化，对真机"未知的正确值"更鲁棒。

### 5. 迁移学习协议（Task 7，到货后执行）

```python
# 加载预训练模型
model = load_model("leak_model_pretrained.h5")

# 冻结底层特征提取层（Conv1D）
for layer in model.layers[:4]:
    layer.trainable = False

# 用真机数据微调顶层
model.compile(optimizer=Adam(learning_rate=1e-5),  # 极低 lr
              loss="sparse_categorical_crossentropy")
model.fit(real_X_train, real_y_train, epochs=5, validation_split=0.2)

# 导出 int8
convert_to_tflite_int8(model, "leak_model_final.tflite")
```
