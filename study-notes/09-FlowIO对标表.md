# 09 - FlowIO 本尊正式对标表（2026-09-21）

> 数据源：CHI'21 论文（本地 PDF）、softrobotics.io 官方 18 页文档（本地镜像，含官方 Limitations 页）、

> 触发：用户质询"对标了 FlowIO 本尊吗"——此前功能架构已对标，本文补正式规格对标与商务模式对标。

## 一、商务模式对标（最重要的发现）

| | FlowIO 本尊 | 我们 |
| --- | --- | --- |
| 获取方式 | **非卖品**：申请→审批→**借用**，用完传给等候名单下一人 | 直接购买 |
| 商用授权 | CC BY-NC-SA，**商用需书面许可**（借来的设备依法不可商用） | 客户可自由商用（我们 100% 自主实现） |
| 中国可得性 | 国际物流+审批+英文沟通，实际近乎零供给 | 本土现货 |
| 支持 | 英文邮件（单人学术项目，时差） | 中文微信/文档/视频 |
| 官方定位原话 | "public good belonging to the public commons"（公共品） | 商业产品 + 开放文档 |

**结论**：竞争叙事从"更便宜的替代"升级为——**"买得到的、可商用的、带数据闭环的"软体机器人气动平台**。
对国内想商用软体气动技术的团队，FlowIO 路径的许可成本实际上是"不可能"，而非"贵"。

## 二、功能/规格对标

| 维度 | FlowIO 本尊（官方数据） | 我们 P0（采购车 BOM） | 我们 P1（目标） | 判定 |
| --- | --- | --- | --- | --- |
| 气动端口 | 5 | 3（P0 用 3 口验证） | 5 | 追平 |
| 泵 | 2 泵，可换模块（小/中/大） | 1×370 充吸两用泵 | 单泵起步，预留双泵位 | 落后（见注 1） |
| 阀 | 7 常闭（5 端口+进气+排气） | 套装 2 三通 + 4 常闭 + 排气路 | 7 常闭同构 | 追平 |
| **最大压力** | **~30psi（207kPa）**，外接气源 6bar | 370 泵约 50–70kPa | 换无刷泵可到 100kPa+ | **落后**（注 1） |
| 流量 | ~3 L/min | 370 泵 3–6 L/min（实测待定） | 同左 | 可追平 |
| **端口压力感知** | **单传感器分时复用**——读某端口要先开它的阀；**Sensors++ 模块付费选装**才有独立传感 | **2 路独立传感（标准配置）** | 5 路独立（标准配置） | **反超** |
| **逐口独立压力闭环** | inflateP 存在但"低层反馈控制"仍在开发，**完整版在付费 Premium 区** | P0 即做 5 路独立闭环 demo | 完整 + 参数可调 | **反超** |
| 多端口并发异操作 | 不支持（同操作可以）；需买 2 台设备 | 单泵架构同样受限 | 同 FlowIO（预留双泵解决） | 平 |
| 控制接口 | BLE（nRF52832，8 服务 15+ 特征）+ Web GUI（Chrome）+ JS API + 串口 | BLE 5 + WiFi + 微信小程序 + 串口 CLI | + Python SDK | 反超（本土生态） |
| 数据层 | 无官方数据报表/记录功能 | 训练/压力曲线报表（小程序） | 数据导出 + 云端可选 | 反超 |
| 供电 | 锂电池（可穿戴优先） | 5V 适配器（P0） | 电池版 V2 | 落后（P0 阶段） |
| 显示/交互 | OLED + NeoPixel + 按键 | 无（P0 面包板） | 状态灯 + 可选小屏 | 落后（阶段性） |
| 时延数据 | **官方承认从未测量** | P0 实测并公开 | 全链路实测报告 | 反超（用数据说话） |
| 文档 | 英文，部分页面更新滞后 | 中文全套 + 视频教程 | 持续运营 | 反超（本土） |

注 1（诚实披露）：最大压力 207kPa vs 我们 P0 泵的 50–70kPa 是真实差距。对策：① P1 泵选型升级（海霖 VBY 正压 100kPa+）；② 或明确定位"0–100kPa 档"——覆盖软体抓持/可穿戴/康复主流应用，把 200kPa+ 让给外接气源场景（FlowIO 自己也是靠外接气源才到 6bar）。

注 2：FlowIO 的单传感器分时复用正是我们 02 笔记第 6 节记录的技巧——我们用 5 路独立传感把它变成"标准配置"，这是成本（+¥180）换的、官方 Limitations 页亲口承认的短板。

## 三、对我方 P0 BOM 的核查结论

1. **BOM 无需修改**：全部物料在"0–100kPa 通用包线"内对标成立；压力上限差距由 P1 泵选型解决，不影响 P0 逻辑验证。
2. **增加两个 P0 实测项**（对标驱动的测试清单增补）：
   - 全链路时延（GUI 点按→阀动作）——官方从未测过，我们测出来就是营销素材；
   - 泵实测 P-Q 曲线——决定 P1 泵选型。
3. **固件需求增补**（对标 FlowIO BLE 服务思路）：状态字广播 + 多设备同步预留（JS API 支持多设备同步是 FlowIO 亮点，我们的协议帧要预留设备 ID 字段）。

## 四、一句话总结

FlowIO 的真实短板不是"贵"（它根本不卖），而是：**借不到、不可商用、无数据层、闭环不完整、无中国支持**。
我们的国产替代在这五点上全部反超；真实落后点只有集成度（P0 面包板 vs 成品）和最大压力（P1 泵选型解决）——
而这两点分别是"阶段问题"和"选型问题"，不是架构问题。

## 五、为什么官方不商业化？（2026-09-21 补充调查）

用户质询："他不下场是不是有隐形坑？"调查结论：**无隐形坑，是三重理性选择**：

1. **身份激励**：作者自述项目是"continuing Ph.D. studies"的一部分——博士生回报=论文/学位/学术网络，非收入；
2. **单位经济学在他侧崩塌**（关键发现）：FlowIO 用 **SMC S070 微型阀**（高端日本件，$50–100/个 × 7）+ MS5837 + 定制件，
   小批量单台造价 $400–600 起——卖即亏，故只能"借用制"。**这正是我们的套利空间**：国产阀 ¥6 vs SMC $50–100，
   成本结构差一个数量级，"国产替代"的逻辑根基就在此；
3. **单人售后无解**：借用制+社群分摊是全球单人研究者的标准解。

排查清单：技术缺陷无证据（官方自述低层 bug 全修）；学术市场极小（官方自述用户"over a dozen people"，
但中国康复/教学/商用场景在其盲区）；无专利命中（初筛，正式 FTO 留 P5）；Premium 合作区证明付费意愿存在。

风险评估：真实风险 = 他博士毕业后 VC 创业化，但其场域（欧美学术）与我方（中国商用+微信生态）比较优势错位，
正面碰撞概率低。注意其 Premium 合作者会获得 PCB/引脚图等文档——我方价值锚在固件+算法+数据层+生态，非硬件抄板。
