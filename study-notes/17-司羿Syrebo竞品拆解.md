## 三、SY-HR03E 技术拆解

### 确认的规格

| 项 | 规格 |
|---|------|
| 驱动 | **气动**（柔性软体机器人，气泵+软体手套） |
| 训练模式 | 6 种：被动/任务导向/辅助/双侧镜像/抗阻/主动游戏 |
| 屈伸时间 | 3-12 秒/次可调 |
| 传感器 | "高精度传感器识别患手微弱主动运动"→ 辅助触发 |
| 视觉反馈 | 屏幕 3D 手部模型 |
| 适用症 | 脑卒中/脑损伤/脑瘫/手外伤/骨科术后 |
| 注册 | **第二类医疗器械** |
| 安全 | "气动原理不伤手"（软体柔性力） |

### 未公开但可推断的

| 项 | 推断 | 依据 |
|---|------|------|
| 通道数 | SY-HR03E 可能 1-2 通道（屈/伸），C12 才有"分指" | "分指训练"是 C12 卖点 |
| 压力范围 | 未知（闭源） | 需拆机 |
| 评估功能 | **无独立评估模块**（传感器仅用于辅助触发） | 官网/手册/文献均未提及评估输出 |
| 数据输出 | 3D 模型仅做视觉反馈，**无 FMA/MBI 量化报表** | RCT 论文用手动 FMA 评分 |
| API/研究接口 | **无**（闭源整机） | 无开发者文档 |

## 四、司羿的护城河 vs 弱点

### 护城河（我们短期打不过的）

| 护城河 | 说明 |
|--------|------|
| **注册证** | 二类医疗器械已拿证（周期 2-3 年，费用百万元级） |
| **临床数据** | 华山医院 RCT 发表 = 学术背书 |
| **品牌/渠道** | "服务全球数百万人次"，医院+电商渠道成熟 |
| **融资** | 近亿元 = 团队 50+ 人，研发/注册/市场并行 |
| **BCI 布局** | HR08P 脑机接口版 = 技术代差布局 |

### 弱点（我们的机会）

| 弱点 | 说明 | 我们的对策 |
|------|------|----------|
| **无客观评估输出** | 传感器只做辅助触发，不给医生量化报表 | FlowIO 的压力数据+算法→FMA 趋势图=核心差异 |
| **闭源无 API** | 研究者无法编程、无法二次开发 | FlowIO 的 CLI+Web GUI+孪生=研究友好 |
| **精细度不足** | HR03E 非分指（C12 才分指但价格更高） | FlowIO 5 端口独立控制=天然分指 |
| **教育/科研市场空白** | 司羿只做临床/家用，不做高校实验平台 | FlowIO-CN 的"Raspberry Pi"定位无直接竞品 |
| **价格断层** | 医用万元级 vs 家用 ¥69 白牌，中间 ¥300-1000 空 | 08 号文档的切口 A 仍然成立 |

### 三线并行的清晰定位

| 产品线 | 定位 | 对标 | 差异化 |
|--------|------|------|--------|
| **FlowIO-CN 教育版** | 气动软体机器人实验平台（¥2980-4980） | **无直接竞品**（司羿不做教育） | 5 端口+孪生+TinyML+API |
| **康复评估工具**（新） | 手指活动度客观测量仪（¥500-1500） | 司羿无此产品线 | FMA 自动估算+压力→角度 |
| **白牌升级方案**（切口 A） | B2B 控制板+固件+小程序（方案价 ¥300-500） | 司羿不做 B2B | 5 路压力闭环+数据报表 |

### 不做的

- ❌ 直接与司羿打医用整机（无注册证、无团队、无渠道）
- ❌ 价格战（司羿家用 ¥2000-3000，我们的 BOM 撑不住）
- ❌ BCI 方向（司羿 HR08P 已布局，我们无 EEG 能力）

## 六、从司羿身上学到的

| 学到 | 应用 |
|------|------|
| 6 种训练模式是标配 | FlowIO 的 Scheduler 天然支持（序列+定时+循环） |
| "虚拟情景/游戏化"提高依从性 | Web GUI 可加简单游戏（Unity/WebView） |
| "微弱主动运动检测"= 辅助触发 | TinyML 压力模式分类→"患者想动"检测→自动辅助 |
| 临床 RCT 是定价权的来源 | 教育/科研线不需要 RCT，康复线必须有（→找临床合作者） |
| 多型号矩阵覆盖全场景 | FlowIO 先做教育版（最轻），康复线等教育版养活后再开 |
