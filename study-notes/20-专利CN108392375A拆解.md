## 执行器设计细节

| 项 | 规格（专利原文） |
|---|------|
| **每指执行器** | 上侧 + 下侧两套中空软体（屈曲 + 伸展 = 双作用） |
| **四指** | 每指 3 段可弯区段（对应 3 个关节）+ 3 段非弯区段 |
| **拇指** | 2 段可弯 + 2 段非弯（对应 2 个关节） |
| **材料** | 高弹性体（一侧平滑+不可拉伸尼龙，一侧三角形凸起） |
| **原理** | 内压增大→三角形凸起膨胀→向平滑侧弯曲 |
| **通道数** | 理论 = (4指×3 + 拇指×2) × 2侧 = **28 通道**（每关节独立控制） |
| **实际简化** | 专利也提到"每个中空软体只对应一个关节"= 可简化为每指上下各 1 通道 |

## 控制算法（专利声明的创新点）

| 算法 | 说明 |
|------|------|
| **迭代学习控制** | 第 n 次运动误差作为第 n+1 次的输入，逐步逼近期望轨迹 |
| **痉挛检测** | 速度/加速度数据偏离期望→判定痉挛→立即停止+声音报警 |
| **多模态切换** | 被动/主动/主被动/阻尼 四种模式自动切换 |
| **主动意愿检测** | 当前角度>气压对应角度 + 速度增大 = 患者主动运动 |
| 云端数据 | 手机 APP + 医师远程查看 + 康复评价 |

| 评估 | 曲率+速度+加速度→康复评价 | 压力数据+TinyML（规划中） | 各有侧重 |

## 关键洞察

1. **双作用执行器是标准做法**——上下两套软体，屈伸都有主动力，不是靠弹性回弹
2. **双泵方案**——一个充一个抽，比单泵+排气阀的响应更快
3. **传感器远多于我们的规划**——每指曲率+加速度+气压=12 个传感器，我们只规划了 2 个气压传感器
4. **迭代学习控制**是一个已验证的康复控制算法——可作为 FlowIO-CN 固件的功能扩展
5. **痉挛检测是刚需**——通过速度/加速度的模式识别实现，与 TinyML 泄漏检测架构相同
6. **拇指只有 2 段**（vs 四指 3 段），与拇指的解剖结构一致（2 个关节 vs 3 个关节）
