## 1. "支持 TinyML 生态"具体化为五个兼容承诺

| # | 承诺 | 实现方式 |
|---|------|---------|
| 1 | **Edge Impulse 兼容**（起步最快） | 固件提供传感器数据流式输出（协议层已有），Edge Impulse 官方支持 S3；训练后导出 Arduino/C++ 库可直接编译进我们的固件（Arduino 兼容层） |
| 2 | **TFLM 兼容**（最通用） | 预留 model partition + `ml_task` 推理任务，挂载 TFLite Micro 运行时 |
| 3 | **ESP-DL/ESP-NN 兼容**（性能最优） | 乐鑫官方 S3 SIMD 加速；模型格式转换走 ESP-DL 工具链 |
| 4 | **数据管道开放** | I2C 压力 50–100Hz → 环形缓冲 → 特征提取 → 1–2s 滑窗；CSV 导出 = 任何平台可训练 |
| 5 | **推理结果标准化上报** | 异常分数/分类走协议层扩展帧（帧格式已预留字段），小程序/上位机可见 |

## 2. 架构（继承笔记 11 铁律）

```
控制路径（确定性）：  传感器 → PID 闭环 / 硬规则超压保护     ← TinyML 永不进入
观察路径（概率性）：  传感器 → 环形缓冲 → 特征 → 推理(低优先级任务)
                              → 异常分数 → 应用层（日志/上报/建议动作）
```

- `ml_task`：独立 FreeRTOS 任务，优先级低于控制任务；推理超时自动降级（丢窗不丢控制）
- 内存：模型 10–100KB 放 flash 新分区（分区表加 `model, data, 0x40, 0x3F0000, 256K`）；PSRAM 启用后特征缓冲入 PSRAM
- **每个模型必须绑定客户价值**（省售后钱/报表增值），拒绝 Bonsai 式为 AI 而 AI

## 3. 杀手锏：数字孪生 = 标注数据工厂

FlowIO 结构性没有的东西：**可控物理仿真 → 无限标注训练数据**。

```
孪生侧（我们已有）                      训练侧                真机侧
twin_api 加"泄漏注入"参数      →    Keras 小模型     →    int8 TFLite
（每阀独立泄漏系数+工况矩阵）      （CNN/自编码器）      烧入 model 分区
批量仿真 → 带ground-truth CSV
```

- Phase 0（立即可做，顺带增强孪生真实性）：`twin_api.c` 每阀加 `leak_k[7]` 系数（纳入比例漏率物理项）；`/api/leak` 注入端点
- 工况矩阵自动生成：压力 × 阀组合 × 泄漏位置/大小 × 泵状态 → 数千条标注样本
- 域差距用真机数据微调（P2 起协议层录 CSV 回流）

## 5. P0 交付边界（现在做什么/不做什么）

- **P0 做**：① 数据流式输出协议（已有）② 分区表预留 model 分区 ③ `ml_task` 骨架（空转+降级逻辑）④ 孪生泄漏注入（Phase 0，兼收物理真实性）⑤ 板卡 I2C/I2S 扩展口确认
- **P0 不做**：训练、部署真模型、采购任何新硬件（BOM 影响 = 0）
- 主机侧单测：特征提取函数、环形缓冲、推理超时降级（进 tests/，21 项体系扩容）
