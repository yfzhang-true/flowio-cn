# 硬件图纸从哪来：自研设计路线

> 回答的问题：没有 FlowIO 的结构件/外壳/PCB 图纸，怎么办？
> 一句话：**图纸是设计输出，不是采购输入**。三条设计流（电路/气路/结构）各有合法参考源，
> AI 能直接产出其中大半的中间交付物，人负责在 EDA/CAD 里落图和打样验证。

## 0. 先破题：为什么"没有 FlowIO 图纸"不构成障碍

1. **法律上不许用**：FlowIO 硬件文件私有 + 官网内容 CC BY-NC-SA（禁商用）。就算拿到，抄了就是侵权。自主设计路线下它本来就不在我们的输入清单里。
2. **技术上不需要**：我们的拓扑与 FlowIO 不同（单泵 + 7 阀 + 5 独立传感器，FlowIO 是双泵 7 阀单传感器）。它的 PCB 布局、外壳形状对我们没有直接复用价值——值得继承的"气路逻辑/安全机制"已经写在 `02-气动控制核心逻辑.md` 里了。
3. **工业标准做法**：任何公司的硬件都是从"器件 datasheet 参考电路 + 官方开发板开放原理图 + 自研"画出来的，从来不是从竞品图纸开始。

## 1. 电路（PCB）设计流

### 合法参考源（行业惯例，随便用）
| 参考 | 内容 | 来源 |
| --- | --- | --- |
| ESP32-S3-WROOM-1 数据手册 | 模块最小系统电路（电源去耦、EN/BOOT、strapping 引脚） | 乐鑫官网，免费 |
| ESP32-S3-DevKitC-1 **开放原理图** | 官方底板完整参考设计（USB、自动下载电路、LDO） | 乐鑫 GitHub 开放 |
| 各器件 datasheet 典型应用电路 | XL1509 buck、AO3400 低边驱动+续流、TCA9548A、XGZP6897D | 立创/厂商官网 |
| 嘉立创/立创 EDA 元件库 | 带封装和原理图符号，直连打样 | 立创 EDA |

### 产出流程（谁做什么）
1. **AI 产出**：原理图连接表（每条网络：从哪个器件哪个引脚到哪个引脚）+ 带 LCSC 编号的 BOM + layout 规则清单（天线净空 15mm、阀驱动走线载流≥1A、功率/数字地分区、测试点）。这份文档细致到"照着连就行"。
2. **人执行**：在立创 EDA（免费、国产、元件库直连嘉立创）里照连接表画原理图、Layout——这是几小时到一天的体力活，不是设计难点。
   - 可选：立创 EDA 有网页版，AI 也能用浏览器代操作，但人画更快。
3. **AI 复核**：画完截图/导出网表给 AI 按清单逐项检查（续流二极管、上拉、丝印、安装孔）。
4. **打样**：嘉立创 PCB + SMT 一条龙，¥300–600/轮。

### 阶段衔接（关键）
**P0 原型阶段根本不需要 PCB**：ESP32-S3 官方开发板 + 传感器/驱动模块 + 面包板即可跑通全部气动逻辑。PCB 是 P1 阶段把验证过的东西"固化"，不是前置条件。

## 2. 气路结构件（汇流板/阀座）设计流

这是 FlowIO 最"独有"的部分，但我们的气路拓扑是自己定义的（单泵、1 进气 + 1 排气 + 5 端口阀），从零设计反而干净：

| 阶段 | 做法 | 需要图纸吗 |
| --- | --- | --- |
| P0 | 宝塔接头 + 硅胶管 + 三通手工搭气路 | 不需要，全是现成件 |
| P1 | 参数化 3D 打印汇流板：内部气道 + 接头螺纹孔（M5/倒刺） | **AI 直接写 OpenSCAD 参数化模型**（气道直径、孔距、阀位全是变量），编译出 STL |
| 量产 | 打印验证 → CNC 铝/注塑 | 沿用同一模型转产 |

OpenSCAD 是代码定义几何，AI 生成/修改它是强项——"阀孔距改成 22mm、气道加深 2mm"就是改一行参数。

## 3. 外壳设计流

- 同样走参数化：OpenSCAD（或 FreeCAD/Fusion 360，人用 GUI 更顺手）生成带 PCB 安装柱、5 个气路出口开孔、Type-C/开关/LED 窗口的壳体。
- **外观注意**：只参考 FlowIO 的功能布局照片（端口在哪、尺寸多小），不复制其造型/配色/Logo——外观专利和商标是独立风险。
- 样机 3D 打印（嘉立创三维猴/本地打印），量产转注塑（开模费另计，V1 不急）。

## 4. 可公开参考的同类开源项目（引用前先查许可证）

| 项目 | 可参考点 | 许可证注意事项 |
| --- | --- | --- |
| ESP32-S3-DevKitC-1（乐鑫） | 底板电路全集 | Apache/MIT 系，可放心参考 |
| Pneuduino（MIT Media Lab） | 早期气动控制板架构思想 | 引用具体电路前确认许可 |
| ProgrammableAir（开源气动板） | 阀驱动/泵驱动电路思路 | 同上；且与我们拓扑差异大 |

原则：**看架构可以，抄电路前查证，抄外观一律不行**。

## 5. AI 在硬件设计里的交付物清单（可直接开始）

1. ✅ 原理图连接表 + BOM（jlcpcb MCP 查价选封装）——文字版，立刻可做
2. ✅ Layout 规则清单 + 原理图复核——按轮次
3. ✅ OpenSCAD 参数化汇流板模型（.scad 源码）
4. ✅ OpenSCAD 参数化外壳模型
5. ✅ 气路装配图（文字版连管表：哪个接头接哪个口）
6. ⚠️ 立创 EDA 代画（浏览器可行但低效，建议人画 AI 审）
7. ⚠️ 3D 模型渲染预览（本机若装 OpenSCAD/FreeCAD CLI 可自动出 STL 并检查）

## 6. 与既有计划的衔接

P0（1–2 周，¥300 物料）**零图纸依赖**：开发板 + 模块 + 管路即可开工。
P1 开始时，上表第 1/3/4/5 项由 AI 提前备好，人只做 EDA 落图与打印件验证——图纸生产不是瓶颈，P0 的实测数据（阀保持占空比、泵 PWM-流量曲线）才是 P1 的真正输入。
