# 10 - P0 连接装配指南（气路拓扑 + 电气接线 + 上电流程）

> 这份文档就是 P0 的"图纸"：所有采购件的连接关系。到货后照此装配。
> 架构原则：**套装（泵+两个三通阀）= 压力源级**，**我们加的常闭阀 = 端口级**，
> **传感器 = 测量级**——三级串联，正好对标 FlowIO 的架构（见第五节）。
> 2026-09-21。装配中发现与本文不符的，以实物为准并把修正记回本文。

## 二、气路连接表（从泵到气囊，共 10 根管）

| # | 从 | 到 | 用什么管/件 |
| --- | --- | --- | --- |
| 1 | 370 泵「充气口」 | 充气三通阀·塑料端 | 套装原配管 |
| 2 | 370 泵「吸气口」 | 吸气三通阀·塑料端 | 套装原配管 |
| 3 | 充气三通阀·对外孔 | **通大气**（悬空即可） | 原配短管 |
| 4 | 吸气三通阀·对外孔 | 通大气 | 原配短管 |
| 5 | 充气三通阀·金属端 | 三通 A（分流用） | 套装原配管 |
| 6 | 吸气三通阀·金属端 | 三通 A 另一端 | 套装原配管 |
| 7 | 三通 A 第三端 | 三通 B（延长汇流管） | 4mm 硅胶管（套装） |
| 8 | 汇流管（三通 B 处） | **XGZP#1 高压口**（经 JT-709 变径 3.2→4.0） | 4mm 管+变径 |
| 9 | 汇流管末端 | 端口阀 A/B/C 的进口（各经一小段管） | 4mm 管 + 三通分路 |
| 10 | 端口阀 A/B/C 出口 | 各自的测试气囊（气球） | 4mm 管；传感器#2 接端口 C 阀后（变径） |

要点：
- **XGZP6897D 是差压传感器（双嘴）**：高压嘴(HA)接汇流管，低压嘴(HB)通大气——差压=表压，正好测相对大气压；
- 端口阀 A/B/C 就是那 4 只常闭阀中的 3 只（第 4 只备用/做泵直驱实验）；
- **保压原理**：端口阀关闭后气囊气路封死——这是 kit 原版做不到、而我们的架构白送的 hold 功能；
- 气嘴口径是全系统唯一待实测项：阀嘴若为 ~3.2mm，用 3mm 硅胶管直插或 JT-709 变径；装好后**肥皂水涂接口查漏**。

## 三、电气接线表

### 3.1 功率侧（5V 强电）
| 从 | 到 | 说明 |
| --- | --- | --- |
| 5V/3A 充电头 | ESP32-S3 开发板 5V 引脚（或 USB 口） | 主控供电 |
| 5V/3A 充电头（并联） | MOS 模块功率输入 V+ / V- | 阀功率回路 |
| MOS 模块输出 CH1/CH2/CH3 | 端口阀 A/B/C 一端（不分极性） | 阀不分正负 |
| 阀另一端 | MOS 模块 V-（GND） | 低边开关回路 |
| kit 的 TYPE-C 口 | 5V/3A 充电头（另一根线） | 泵+PWM开关供电 |

### 3.2 信号侧（3.3V 弱电，杜邦线）

> 2026-09-22 依厂商资料包（YD-ESP32-S3 SCH-V1.4 + 16R8 产品介绍）与 `hal_esp32.c` 对齐修订。

| ESP32-S3 GPIO | 接到 | 功能 |
| --- | --- | --- |
| GPIO4 | MOS 模块 IN1 | 端口阀 A（固件 PORT1，LEDC ch0） |
| GPIO5 | MOS 模块 IN2 | 端口阀 B（PORT2） |
| GPIO6 | MOS 模块 IN3 | 端口阀 C（PORT3） |
| GPIO7 | MOS 模块 IN4（备用） | PORT4（P0 只装 3 阀，此路空置） |
| GPIO10 | MOS 模块 IN5（备用） | PORT5（同上空置） |
| GPIO15 | PWM 电子开关·泵（白线） | 50Hz 舵机 PWM：180°开/0°关 |
| GPIO16 | PWM 电子开关·充气阀 | 同上（固件 INLET 角色走这只舵机） |
| GPIO17 | PWM 电子开关·吸气阀 | 同上（固件 VENT 角色走这只舵机） |
| GPIO8 | I2C SDA → 传感器#1/#2、TCA9548A | I2C 数据 |
| GPIO9 | I2C SCL | I2C 时钟 |
| GPIO21 | （暂不接） | 泵 PWM 直驱实验预留（LEDC ch7） |
| GND | 与 MOS 模块 GND、kit GND **共地** | ⚠️ 必须共地，否则信号无效 |

**避坑（引脚黑名单，YD-ESP32-S3/HW-678A 实测原理图核对）**：
- GPIO0（BOOT 键）、GPIO3/45/46（strapping）不要用；
- GPIO19/20 是原生 USB（OTG 口，需焊 0Ω 桥接才能用）不要用；
- **GPIO35/36/37 被 N16R8 的 Octal PSRAM 独占，物理上不可用**（sdkconfig 已改 SPIRAM_MODE_OCT@80M）；
- GPIO43/44 是串口 U0TXD/U0RXD（板载 CH343P）不要用；
- GPIO48 = 板载 WS2812 RGB（地址型灯珠）——将来做状态灯用它，别接外设；
- 烧录/monitor 用**丝印 COM 的 Type-C 口**（CH343P 串口，Win11 通常免驱；另一口是 OTG/JTAG）。

**板卡出厂行为**：出厂固件是 AP 模式（WiFi 名 "ESP32-Access-Point"），RGB 灯连上 WiFi 才亮——首次上电看到 RGB 不亮属正常，不是板子坏。
（PWM 电子开关的红线=5V、黑线=GND 来自 kit 自己的供电，白线=信号接上表 GPIO。）

## 四、首次上电流程（到货后按序执行，前 4 步不接任何气路）

1. **目检**：逐个模块看有没有运输损坏、排针歪斜；
2. **电气干测**：ESP32 单独上电（不接 MOS/kit），烧一个"GPIO 翻转"程序，万用表量 GPIO4/5/6/7 有无 3.3V 输出；
3. **驱动级测试**：接上 MOS 模块+一只阀（不接气路），点 GPIO → 听阀"咔哒"、万用表量阀两端 5V；
4. **I2C 扫描**：接两只传感器，跑 I2C Scanner——确认两个地址都出现（同址则改接 TCA9548A）；
5. **气路装配**：按第二节接管，肥皂水涂所有接口，泵运行 10 秒查气泡（漏点=重新插紧/换管）；
6. **单端口循环**：手动命令：开端口阀 A → 泵充气 3 秒 → 关端口阀 A（保压）→ 切排气位释放。三个端口逐个过；
7. **闭环 demo**：固件跑"端口 A 充气至目标压力自动停"——这就是给实验室看的销售材料视频。

## 五、与 FlowIO 本尊的架构映射（对标视角）

| FlowIO 架构层 | 我们的 P0 对应 |
| --- | --- |
| 泵模块（2 泵可换） | 370 充吸泵 ×1（充吸两用，P1 换无刷泵提升压力） |
| 进气阀+排气阀（2 个） | kit 的充气/吸气三通阀（对外孔=排气路径）——**kit 白送的** |
| 5 个端口阀（常闭） | 我们的 NC 常闭阀（P0 装 3 个） |
| 单传感器分时复用 | 2 路独立传感起步（FlowIO 要加钱买 Sensors++） |
| 8 个 BLE 服务 + 15 特征 | ESP32-S3 BLE + WiFi + 小程序（协议帧留设备 ID 字段，为多设备同步预留） |
| GUI（Chrome Web Bluetooth） | 微信小程序 + 串口 CLI |
| 电池+OLED（可穿戴优先） | P0 无（V2 加） |

## 六、风险提醒（装配时最可能翻车的 4 处）

1. **阀气嘴口径**（~3.2mm vs 管 4mm）：备了 3mm 管 + JT-709 变径；插上先手测气密；
2. **MOS 模块触发方式**：详情页"手动控制"存疑——先做第四节第 3 步验证，不行换模块（¥10）；
3. **供电**：必须 5V/3A 充电头，电脑 USB 会欠压；
4. **共地**：三路电源（ESP32/MOS/kit）的 GND 必须连在一起。

## 七、上位机连接与多设备通信（补充）

**物料不直接连电脑**——所有传感器/执行件挂在 ESP32 上，ESP32 是唯一通信枢纽：

```
P0:  传感器→I2C→ESP32→USB 串口→电脑 CLI（115200）
P2+: ESP32→BLE→微信小程序；ESP32→BLE/WiFi→Python SDK
```

- **USB-C 数据线**：需确认一根支持数据的 C 口线（纯充电线不行，常见漏购项）；
- 电脑端串口终端：`idf_build.sh monitor` 或 PuTTY @115200。

**多设备预留**（P0 单板，P2+ 启用）：协议帧已含设备 ID 字段位。方案对比：
ESP-NOW（同步抖动 1–5ms，设备间硬实时同步首选）/ BLE 星型（手机主机连 N 台，对标 FlowIO JS 多机模式）/ WiFi UDP（局域网+大数据）。康复双设备（左右手）同步需求 <20ms → ESP-NOW 补充通道 + 小程序主机星型，双方案并存。
