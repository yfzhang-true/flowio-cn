## 二、Xie 2026（Advanced Science，CUHK 汤启宇组 + 天津大学）——拇指精细动作的现成答案

`literature/2026-xie-advsci-portable-thumb-glove.pdf`（12 页，已提取 txt，DOI 10.1002/advs.76275，CC-BY）

### 关键事实

| 维度 | 数据 |
|------|------|
| 执行器 | **连续分段双腔折纸（origami）拇指执行器**：单一执行器覆盖 CMC 双向（外展/内收 + 屈/伸）+ MCP 屈伸 + IP 伸展板（被动） |
| 力学 | 指端力 **18 N**（约为典型中风痉挛所需 2 倍）；耐压 150kPa；端部承重 60 N；锥角 0→15° 显著增力 |
| 控制 | **双腔差压协调**：一腔充 + 一腔抽真空 → 弯曲角 143°（单腔仅 102°）——**正压+负压组合是拇指全范围的关键** |
| 传感器 | **XGZP6857A（-100~300kPa，CFSensor）压力传感器** + IMU JYP61（WitMotion）×2（指尖+手腕测角）+ 力传感器 DYMH-103 + 前臂 sEMG×2（意图触发） |
| 控制 | **贝叶斯优化人机闭环"按需辅助"（AAN）**：7 周期采样→5 周期单目标（先达角度）→双目标（最小辅助力+保持角度） |
| 驱动 | **单泵系统**（便携性优先）+ 多阀切换 |
| 制造 | 3D 打印原型→硅胶模→注塑（DPI 8400，银科）→压缩+220°C×30min 回火——**非织物路线**，DIY 难度高 |
| 验证 | 3 名慢性中风（重/中/轻）：捏合力 +62.9%，拇指环转 ROM ×9，全部完成捏/侧捏/对指/刷手机/拧瓶盖/环转 |
| 寿命 | 5850 循环至破损，弯曲角衰减 4.2%；迟滞 13%（力）/18%（角） |
| 解剖需求 | CMC 外展/内收 **-8°~16° 覆盖 100% ADL**；拇指力矩 0.06-1.4 N·m；ADL 指端力 3-9 N |

### 对 FlowIO-CN 的决策

1. **传感器选型被顶刊背书**：XGZP6857A 正是我们 BOM 的 XGZP 系列（CFSensor）——白牌厂商沟通时可直接引用 Advanced Science 论文作选型依据
2. **拇指通道预算修正**：拇指要"真精细"，需要 **2 腔差压控制**（1 充 1 抽）——正压+真空双能力（我们已有 PUMP_P_MIN=-38kPa 真空能力 ✓）；Pro 版拇指 = 2 通道
3. **IMU 是比曲率传感器更便宜的测角方案**：JYP61（维特智能，淘宝 ~¥15-30）vs 曲率传感器——Pro 版传感器矩阵可改为"每端口 1 压力 + 每指 1 IMU"
4. **AAN 控制是固件算法路线图的官方方向**（综述也确认）——与我们的 TinyML 架构同栈：先做 PID 闭环 → TinyML 泄漏检测 → 远期 AAN
5. 拇指解剖指标（-8~16°、3-9 N、0.06-1.4 N·m）直接作为 Pro 版验收规格
6. 折纸执行器制造（注塑+回火）超出 DIY——**拇指 Pro 版硬件可外购/合作，我们只做"大脑"**，符合 B2B 定位

## 三、Yilmaz 2026（Advanced Materials Technologies 综述，ITÜ）——行业地图与竞争定位

`literature/2026-yilmaz-amt-fabric-gloves-review.pdf`（40 页，已提取 txt，CC-BY，DOI 10.1002/admt.202502282）

### 关键事实

1. **织物执行器 5 大制造家族**：编织 braided（McKibben 类，高力）/ 缝纫 sewing（可编程各向异性）/ **焊接层压 welded/laminated（我们的 CNC 热封属此类：整体气腔气密性好，界面是疲劳弱点）** / 混合 hybrid / 针织 knitted（舒适+可批量定制+传感器可共织，Review 作者自家路线）
2. **选型结论**："背侧大力矩→编织；康复长时穿戴→针织"——CNC 热封是中间态：气密+可定制+设备门槛低
3. **开环控制被明确判死刑**："对外骨骼手套这类多自由度应用，无传感器的开环控制精度根本不够"——迟滞 13-18%+材料非线性
4. 控制输入模式枚举：按键 / sEMG / 健手数据手套 / **预编程循环**（=Scheduler）
5. **PWM 驱动阀=节能+延寿**（我们有 ✓）
6. 未来控制方向：MPC、强化学习、学习辅助控制
7. **行业痛点 = 我们的机会**："绝大多数设备仅实验室验证；无统一测试协议和国际标准；力和 ROM 各研究差异巨大"

### 对 FlowIO-CN 的决策

1. **¥69 白牌（开环+无传感）在综述框架里是"被淘汰的架构"**——我们的 5 路压力闭环+数据报表正打在这个缺口上，B2B 话术直接引用综述结论
2. **无统一测试标准 → 我们的 FMA 趋势报表可以成为"事实标准"**——厂商采购我们的方案=获得可量化的评估输出
3. 制造路线定位清晰：CNC 热封（welded/laminated）是我们推荐的执行器工艺（DIY 友好），针织是远期观察（传感器共织很有吸引力但需针织机）
4. 界面疲劳是焊接类执行器的命门 → 我们的 **TinyML 泄漏/老化检测正打在这个行业性弱点上**（5850 循环衰减 4.2% 也是证据）——卖点 2 有了文献级的行业痛点支撑

## 四、Xu 2026（Uppsala 博士论文）——无电子气动回路：观察项，非路线

`literature/2026-xu-uppsala-pneumatic-circuits-thesis.pdf`（54 页 kappa，2026-02-27 答辩，考官 Jamie Paik/EPFL）

### 关键事实

- 无电子气动逻辑：热插拔夹管阀、常开/常闭阀、AND/OR/NAND/NOR 布尔运算、传感器-阀反射回路（全自动抓取/触觉反馈）
- **多路复用（multiplexing）：用少量信号控制大量执行器**——Paper I 的 SPAM 矩阵
- 气动-电学类比表：P↔V、Q↔I、流阻↔电阻、阀↔开关；RC 充放电 ↔ 气腔充放气（一阶系统时间常数 τ）

### 对 FlowIO-CN 的决策

1. **RC 类比为一阶充放气建模提供理论框架**——我们的孪生物理 v2（孔口方程+多变过程）与此自洽，可在 PHYSICS-SPEC 补一句文献依据
2. **多路复用是 Pro+ 版阀数优化的备选**（12+ 通道时阀成本占比上升）——暂不采用（增加气路复杂度），记入技术雷达
3. 无电子路线适合 MRI 兼容/潜水等 niches——**与我们的"电子大脑"B2B 定位正交，不构成竞争，观察即可**

## 四点五、Wang 2022（Applied Sciences 12:3735，千叶大学）——拇指通道数的对照实验裁决

`literature/2022-wang-appsci-thumb-assist-comparison.pdf`（18 页，已提取 txt，CC-BY，DOI 10.3390/app12083735）

### 关键事实

| 维度 | 数据 |
|------|------|
| 两种执行器 | **3C-ACT**（整指三腔：中腔=屈曲渐细向上、左腔=外展、右腔=内收渐细向下，腔间独立可加）vs **M-ACT**（模块化 23mm，PLA 模+DragonSkin 20 铸造；CMC 单元=双模块+尼龙线连接，每腔负责 2 个方向=耦合） |
| 单自由度辅助 | **M-ACT 胜**：外展时无多余屈曲（结构上下+左右双对称）；3C-ACT 外展时有多余屈曲（仅左右对称） |
| 多自由度（对掌） | **3C-ACT 胜**：Kapandji 评分 **0-8 满分** vs M-ACT 0-5（碰不到小指——屈曲/外展互相挤占，手动调压极难） |
| 最优组合 | **3C-ACT（拇指）+ M-ACT（四指）**：全部 Kapandji 位 + 最强捏合 |
| 力学 | 3C-ACT 指端力 6.0N；M-ACT 5.2N；被动肌腱参考 8.8N；最佳拇-食捏合 **6.2N**（≈抓 1.3kg 物体）；对照此前研究仅 1.66N |
| 拇指 ROM 需求 | IP 89°、MCP 32°、CMC 屈 13°、CMC 外展 38°（健康成人 OpenCV 实测） |
| 临床意义 | 拇指缺失=**40% 手功能丧失**、23% 全人残损；M-ACT 适合重度挛缩患者（单自由度分离训练），3C-ACT 适合进阶抓握/捏取 |
| 测量法 | **Kapandji 测试**（0-10 分拇指对掌临床量表，9/10 罕用省略）+ 增强：三轴力传感器测捏合力 |
| **作者留下的空位** | "**三腔和模块化执行器的控制方法尚待开发**"（原文："control methods for the three-chamber and modular actuators must be developed"） |

### 对 FlowIO-CN 的决策

1. **拇指通道数有了三方案对照表**（全部文献背书）：

| 方案 | 通道 | 控制复杂度 | 性能 | 出处 |
|------|------|----------|------|------|
| 单腔外展 | 1 | 最简 | 仅外展，无对掌 | Chen 2026 |
| **三腔独立（3C-ACT）** | **3** | **简（独立可加，直接调各腔）** | **Kapandji 满分** | **Wang 2022（本文）** |
| 双腔差压（折纸） | 2 | 中（一充一抽，需 P+V 协调） | 18N/143°，86.8% ROM | Xie 2026 |

   **推荐 Pro 版首原型用 3C-ACT 三腔**：控制逻辑最简单（各腔独立 PWM+闭环，无差压协调），且 4 指×2+拇指 3 = **11 通道**，正好落在 12 通道预算内还余 1 路；Xie 折纸方案作为高力替代（其执行器需注塑+回火，外购更现实）。
2. **Kapandji 评分纳入评估输出路线图**：FMA 趋势 + Kapandji 对掌评分——面向康复科医生的报表双指标（Yilmaz"行业无统一标准"的机会再+1）。
3. **Wang 的"控制方法待开发"= 我们的市场定位原文**：执行器设计论文到控制方案之间有断层，B2B"升级大脑"正是补这个断层——写进厂商话术。
4. 硅胶铸造（PLA 模+DragonSkin）与 CNC 热封（TPU 织物）**两条 DIY 制造路线都有论文验证**，白牌厂商可按现有工艺二选一，我们只管控制侧。
