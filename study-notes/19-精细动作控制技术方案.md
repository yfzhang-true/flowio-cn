## 一、临床需求 → 技术指标映射

| 临床需求 | 技术含义 | 所需气动通道 |
|---------|---------|-------------|
| 单个手指屈伸 | 每指独立弯曲/伸展 | 每指 1-2 通道 |
| 对指（拇指→指尖） | 拇指屈曲 + 外展协调 | 拇指 ≥2 通道 |
| 拇指内收/外展 | 拇指横向运动 | 拇指额外 1-2 通道 |
| 拇指旋转（对掌） | 复合运动（屈+展+旋） | 拇指 2-3 通道或特殊结构 |
| 旋转（前臂/腕） | 不在手套范围内 | 不考虑 |

**总计：5 指 × 1-2 + 拇指额外 = 最少 6 通道，理想 8-10 通道**

**FlowIO-CN 当前：5 端口 + 进气 + 排气 = 7 阀**——刚好能做基础分指（5 指各 1 通道），但拇指精细动作需要更多通道或更巧的执行器设计。

## 二、文献找到的三条技术路线

### 路线 A：织物基双作用执行器（2026 最新，最完整）

**来源**：[An Ergonomic, Customizable Soft Robotic Glove](https://arxiv.org/html/2604.00768v2)（arXiv 2026, Chen Rui 等）

| 项 | 方案 |
|---|------|
| **材料** | TPU 涂层尼龙织物（40D 单面 + 20D 双面）|
| **制造** | **CNC 热封**（FDM 3D 打印机改装为热封头，G-code 控制路径）|
| **每指通道** | **2 通道**（屈曲腔 + 伸展腔 = 双作用）|
| **拇指** | **额外 1 个外展执行器**（置于拇指与食指间）|
| **总通道** | 5 指 × 2 + 拇外展 1 = **11 通道**（12 路电磁阀驱动）|
| **控制** | **ESP32** + 12 路微型电磁开关阀 + Wi-Fi 手机界面 |
| **压力** | 50-100 kPa |
| **重量** | 全手套仅 **90 g** |
| **性能** | 指尖力 12.2 N、捏合力 9.8 N、抓握力 24.8 N |

**关键启示**：
1. **与 FlowIO-CN 技术栈高度重合**（ESP32 + 多路电磁阀 + Wi-Fi 控制）
2. 制造用 **CNC 热封而非硅胶模具**——更便宜、更薄、更轻
3. 12 路阀 = 我们的 7 路需扩展或用时间复用
4. 定制化 = 根据患者手指关节几何反推热封路径

### 路线 B：仿生拇指多方向弯曲执行器（2025，天津理工）

**来源**：[Thumb-inspired Multidirectional Bending Soft Pneumatic Actuator](https://www.sciencedirect.com)（Hao Tianze 等，Sensors and Actuators A 2025, 天津理工大学）

| 项 | 方案 |
|---|------|
| **原理** | 纤维增强 + 对称双 IP 关节 + 放大 MCP 关节 |
| **特点** | **双方向侧弯**（左右各弯）+ 大幅度屈曲 |
| **性能** | 侧弯刚度 29.24 N/m、90 kPa 下 48° 复合屈曲、侧向力 0.38 N |
| **耐久** | 800+ 循环无疲劳 |
| **应用** | 已验证三指夹持器（旋转步态拧灯泡/瓶盖）+ 四指仿人手 |

**关键启示**：
1. 拇指的**对掌**不一定要额外通道——通过执行器几何设计（对称腔+大 MCP），一个通道可实现复合运动
2. **纤维增强**（Kevlar/玻璃纤维缠绕）控制膨胀方向，比纯 PneuNet 更精确

### 路线 C：3 腔拇指执行器（3C-ACT，经典方案）

**来源**：[Towards an Extensive Thumb Assist](https://www.mdpi.com)（Wang Y 等，MDPI Actuators 2022）

| 项 | 方案 |
|---|------|
| **拇指** | **3 腔独立控制**（3C-ACT）：屈曲、外展、对掌各一个腔 |
| **四指** | 模块化执行器（M-ACT）各 1 通道 |
| **总通道** | 3 + 4 = **7 通道**（与 FlowIO 的 7 阀完美匹配！）|
| **局限** | 大多数研究把拇指对掌简化为耦合运动而非独立控制 |

## 三、技术方案综合（FlowIO-CN 落地建议）

### 方案一：最小改动（7 通道，现有硬件）

```
通道分配：
  端口1-4 → 食指/中指/无名指/小指（各 1 通道，屈伸）
  端口5   → 拇指屈曲
  进气阀  → 泵充气（复用）
  排气阀  → 排气（复用）

拇指精细 = 用执行器几何解决（路线 B 的对称腔设计）
  → 屈曲 + 几何诱导的外展 = 近似对掌
  → 优点：0 额外硬件改动
  → 缺点：拇指独立外展/内收不可主动控制
```

### 方案二：B2B 增强版（11-12 通道，白牌 Pro 版）

```
通道分配：
  每指 2 通道（屈+伸）× 5 = 10 路
  拇指外展 = 1 路
  总计 = 11 路（12 路阀，1 路冗余）

硬件变更：控制板从 7 阀 → 12 路微型电磁阀
固件变更：pn_core 的 PN_VALVE_COUNT 从 7 → 12
         PN_PORT_MASK_ALL 从 0x1F → 支持 11 通道
成本增加：5 个额外电磁阀 ≈ ¥25（1688 单价 ¥5）
```

### 方案三：极致轻量（5 通道，白牌基础版）

```
通道分配：
  5 指各 1 通道（只做屈曲，伸展靠弹性回弹）
  = 当前 FlowIO-CN 硬件零改动
  = 白牌 ¥69 款的"分指升级版"
```

### 推荐产品矩阵

| 版本 | 通道 | 功能 | 目标 | 硬件改动 |
|------|------|------|------|---------|
| **基础版** | 5 | 5 指独立屈曲 | 白牌入门升级（¥299 零售） | 零改动 |
| **Pro 版** | 11 | 5 指屈伸 + 拇外展 | 白牌高端（¥499 零售） | +5 阀 ¥25 |
| **科研版** | 11 + TinyML | Pro + 数据采集 + API | 高校实验室（¥2980-4980） | 同 Pro |

## 四、制造工艺对比

| 工艺 | 材料 | 成本/套 | 周期 | 精度 | 适合 |
|------|------|---------|------|------|------|
| **硅胶模具**（PneuNet 经典） | Ecoflex 00-30 | ¥50-100 | 4h 固化 | 中 | 科研原型 |
| **CNC 热封**（2026 最新） | TPU 涂层织物 | ¥20-40 | <1h | 高（定制） | **量产 B2B** |
| **3D 打印**（FDM 直接打印） | TPU 95A | ¥30-60 | 2-4h | 低-中 | 快速迭代 |
| **缝合 + 热熔**（手工） | 布+膜 | ¥10-20 | 1-2h | 低 | 白牌现状 |

**B2B 推荐：CNC 热封**——用二手 FDM 3D 打印机（¥500）改装热封头，TPU 涂层织物按米购（1688 ¥15/米），每套成本 ¥20-40，可按客户手指几何定制。

## 五、对 FlowIO-CN 固件的具体影响

### 不变的
- pn_core 逻辑层（动作/闭环/协议）——通道数是 HAL 层参数
- Web GUI / 数字孪生——只需改 SVG 端口数
- TinyML 管线——传感器数据维度可能增加（11 压力传感器 vs 当前 2 个）

### 需要改的（B2B Pro 版）

| 组件 | 改动 | 工作量 |
|------|------|--------|
| `types.h` | `PN_VALVE_COUNT` 7→12 | 1 行 |
| `types.h` | `PN_PORT_MASK_ALL` 0x1F→0x7FF | 1 行 |
| `pn_hal_esp32` | LEDC 通道 7→12 | ~20 行 |
| 硬件 | 电磁阀驱动 7→12 路 | PCB 改版 |
| 传感器 | XGZP 2→5+（每指一个端口侧传感器） | BOM +¥60 |
| `gui.html` | SVG 气路图 5 端口→5+拇外展 | 视觉更新 |

**固件改动总计 ≈ 50 行代码 + PCB 改版**——pn_core 的分层架构在这种扩展场景下的价值终于体现。

### 专利证据补充（2026-09-22，详见 study-notes/20）

对专利 CN108392375A（郑州大学，气动康复手套）的拆解进一步验证/修正了上表：

| 维度 | 专利方案 | 对 FlowIO-CN 的修正 |
|------|---------|---------------------|
| **气泵** | **双泵**（1 充 + 1 抽） | Pro 版 BOM 应规划第 2 个泵（或保留单泵+真空阀，成本权衡） |
| **执行器** | **上下双作用**（屈曲+伸展都有主动力） | 与路线 A（织物双作用）一致——**双作用是行业标准做法**，非可选 |
| **传感器** | 气压×2 + 曲率×5 + 加速度×5 = 12 个 | 佐证"传感器远多于我们规划"——TinyML 数据维度规划应为 12 维预留 |
| **控制** | 迭代学习控制 + 痉挛检测（加速度模式识别） | 痉挛检测与 TinyML 架构同源，可作为固件算法路线图功能 |
| **拇指** | 2 段（vs 四指 3 段），符合解剖 | 佐证拇指通道数不必与四指相同 |
