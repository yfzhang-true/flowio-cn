# FlowIO 公开底层库阅读清单

> 对象：`E:\FLOWIO\FlowIO-Arduino-Libraries-master\FlowIO_Library_2026.03.23\`
> 全库仅 **980 行**（.h + 8 个 .cpp），一个下午可精读完。
> 注意：GitHub 上**不存在** "Pneumatic-Driver" 和 "Pneumatic-API" 两个独立仓库——
> 这两层都在这一个库的 `FlowIO_Driver.cpp` 和 `FlowIO_Pneumatics.cpp` 里。

## 推荐阅读顺序（由概念到实现）

| 顺序 | 文件 | 行数 | 重点看什么 |
| --- | --- | --- | --- |
| 1 | `FlowIO.h` | 175 | 整个 API 的骨架：3 个枚举（配置/单位/组件）、引脚映射表、16 位 `_hardwareState` 状态字的位定义、公开方法签名。**先读这个，后面所有文件都是它的实现** |
| 2 | `FlowIO_Pneumatics.cpp` | 75 | 气动动作层：`startInflation` / `startVacuum` / `startRelease` / `stopAction` 各自开哪些阀、开哪个泵、配置如何门禁动作 |
| 3 | `FlowIO_Driver.cpp` | 139 | 单元件驱动层：泵 PWM、阀开关、端口位掩码三种操作（set/open/close）的语义差异、`optimizePower()` 阀保持电压节能机制 |
| 4 | `FlowIO_CommandControl.cpp` | 84 | 3 字节指令协议（**公开的**）：ASCII 动作码 + 端口位掩码 + PWM；`'?端口'` 的单传感器分端口测压技巧 |
| 5 | `FlowIO_PressureSensing.cpp` | 223 | MS5837-30BA 全流程：复位→读 PROM 校准→CRC4→转换 D1/D2→二阶温度补偿→五种单位换算。算法本身来自传感器数据手册，可独立从手册重写 |
| 6 | `FlowIO_FeedbackControl.cpp` | 121 | 非阻塞压力闭环 `inflateP()` / `inflateP_diff()`：用公开标志位 + 运行标志实现"在 loop() 里反复调用"的状态机写法 |
| 7 | `FlowIO_FeedforwardControl.cpp` | 31 | 时间开环（阻塞式）：动作→延时→停止。注意 `inflate2xT`/`vacuum2xT` 在 .h 里声明了但此版本未实现 |
| 8 | `FlowIO_Indicators.cpp` | 88 | 状态查询（`getHardwareStateOf`）、启动时间表、软关机（`powerOFF()` 拉高引脚 13）、NeoPixel 状态灯 |
| 9 | `FlowIO.cpp` | 44 | 构造函数与引脚初始化（全部用 `analogWrite` 初始化为 0，不用 `digitalWrite`——注释解释了原因） |

## 值得跑一遍/读一遍的示例（Examples/ 下共 236 个，挑这 6 个）

| 示例 | 学什么 |
| --- | --- |
| `InflateUntilPressure` | inflateP 压力闭环的标准用法（loop 轮询 + complete 标志复位） |
| `Inflate_for_3_seconds_nonblocking` | 非阻塞时间控制的写法（不用 delay） |
| `Btn_inflateP_show_dT` | 按钮触发 + 显示充气耗时 |
| `FlowIO_SelfTest_2024` | 官方整机自检流程（逐个元件验证）——可参考做你自己的产测固件 |
| `Pressure_Drop_Test` | 保压性能测试思路（你的产品也需要气密性测试项） |
| `LinearIO` | 线性化输出/渐变控制思路 |

## 公开库里**没有**的东西（别浪费时间找）

- BLE 固件层（GATT 服务定义、蓝牙命令分发、多设备同步）——私有
- JavaScript Web API / Web GUI / GUI Styles——私有
- Web Connectivity（远程通信）——私有且未稳定发布
- 电源管理固件（Auto Power OFF 的定时器逻辑在固件层，库里只有一个 `powerOFF()` 软关机调用）
- OLED 示例只是屏幕玩法，与气动控制无关（可跳过）

## 版本说明

`FlowIO_Library_2026.03.23/` 是最新版（本清单基于它）；`2024.11.11/`、`OLD/` 是历史版本，只在追某个行为的历史变化时才需要看（Changelog.txt 有逐版本变更记录）。
