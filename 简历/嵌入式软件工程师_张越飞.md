### FLOWIO-CN — 开源气动软体机器人控制平台（独立研发）｜2026.07 – 至今

ESP32-S3 · ESP-IDF · FreeRTOS · C · NimBLE · Python · KiCad ｜ **github.com/yfzhang-true/flowio-cn**

背景：空窗期全职投入的产品级开源项目（MIT FlowIO 的国产化替代，面向康复手套等 B2B 场景），一人独立完成硬件到软件全栈交付，代码与硬件全部开源可验证。

- **固件架构**：基于 ESP-IDF + FreeRTOS 设计"平台无关 C 逻辑层（pn_core）+ 硬件抽象层（HAL）"双层架构，pn_core 在主机端 33 项单元测试全绿，业务逻辑与芯片解耦、可移植、可测试。
- **外设驱动开发**：实现 TCA9548A I2C 八路复用、WS2812 RMT、8 路 PWM 比例阀等驱动，覆盖 I2C 总线时序、RMT 外设配置与实时调光调压控制。
- **BLE 应用**：基于 NimBLE 实现 BLE GATT 四服务（Command / Telemetry / Config / DeviceInfo），配套 Web Bluetooth 前端，浏览器免 App 直连设备调试。
- **Python SDK**：开发 flowio_sdk，实现 0xA5 协议编解码，CRC-8 校验与固件同源测试向量双向验证，保证跨语言实现一致。
- **测试自动化**：搭建五层共 181 项测试用例、200+ 断言的自动化测试体系（主机单元 33 / Web 44 / API 50 / E2E 43 / 协议一致性 11），固件回归验证全程自动化。
- **硬件与制造**：独立设计 4 层 PCB（90×75 mm），DRC 违规从 146 项清零（freerouting 3 轮自动布线 + 铺铜修复 + 自研 boardgeom 全障碍路由库）；JLC 标准版 SMT 107 件全代工，BOM 的 LCSC 编码覆盖率 100%；FreeCAD 建模式 3D 打印外壳。
- **数字孪生与文档**：Three.js 实现 3D 爆炸视图与气流/电流实时可视化的 Web 数字孪生；撰写 94 页 LaTeX 专著《气动软体机器人自研实战》（31 条参考文献，一致性审查 16 项清零）。
