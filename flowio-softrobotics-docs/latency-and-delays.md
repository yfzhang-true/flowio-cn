Latency and Operating Delays  

One of the best characteristic of this platform is that the latency and time delays when a user interacts with FlowIO via the Graphical User Interface are imperceptible and everything feels instantaneous. 

Nevertheless, even if imperceptible, time delays and latency are present, due to the following causes:  
\- Pump switching times

\- Valve switching times

\- Bluetooth latency

\- Code execution time

The applications for which FlowIO has been used until now have not required exact knowledge of those time delays, therefore I have not measured them yet. If you are interested in this information, let me know and I can do some measurements.
