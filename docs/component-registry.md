## 5. 过压防护（新增硬约束——泵能力 vs 阀额定）

- 泵死头 **+120kPa / -60kPa** >> F0520 阀额定 **±45kPa** → 气路任一密闭段满压即超阀额定；
- **闭环调压强制**（非可选）：XGZP 实时监测歧管 M + 泵 PWM 调速，工作带目标 **≤+35kPa / ≥-35kPa**；
- 固件互锁：泵运转必须 ≥1 通道阀开启；真空钳位由 -50 收紧至 **-40kPa**；
- P2 可选：机械泄压阀 50kPa（保险冗余，B2B 认证叙事）；传 XGZP 过压即停泵告警。
