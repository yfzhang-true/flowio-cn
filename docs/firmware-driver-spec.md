## 1. 压力传感驱动 — XGZP6897D 100KPDPN（非-C，定案）

BOM 为**非-C** 变体（`-C` 0x58 仅备选）。两者引脚兼容、**寄存器协议不同**——固件按下表实现，
不得混用 `-C` 的 0x04 连读流程（历史事故：PHYSICS-SPEC.md 曾按 -C 修正过一轮，本表为准）。

| 项 | 值 |
|---|---|
| I2C 地址 | **0x6D**（7bit，不可定制） |
| 总线 | ≤400kHz，SDA/SCL 上拉 4.7kΩ，VDD-GND 就近 0.1µF |
| 引脚 | 2=VDD / 6=SDA / 7=SCL / 8=GND；**1/3/4/5 = N/C 禁止连接** |
| 电源 | 2.5~5.5V（本机 3.3V 轨），待机 100nA，ESD 4kV，过载 2× |
| 量程/精度 | -100~100kPa 表压（DPN），±2%Span，24bit，响应 2.5ms，上电 24ms |
| 气路 | P1=高压端接管（⌀3.22 倒钩，3mm 管过盈），P2=低压端大气开放（表压读法） |

### 1.1 采集时序（寄存器流程）

```
上电 → 延时 ≥24ms（上电启动窗）
循环（50ms 控制节拍内）：
  1. 写 0x30 ← 0x0A            # CMD: 组合采集（压力+温度一次触发）
  2. 轮询 读 0x02 (Status)     # 等待 Sco（忙标志）清零——响应 2.5ms@默认 OSR
  3. 读 0x06/0x07/0x08         # 压力 24bit（MSB/MID/LSB，有符号补码和）
  4. 读 0x09/0x0A              # 温度 16bit
换算：
  P [count] = ((0x06<<16)+(0x07<<8)+0x08) 补码
  P [kPa]   = P_count / k      # k 查表按量程 Span；本机型 Span=200（±100kPa）→ k=32
  T [℃]    = T_raw / 256
诊断：0x01 PartID 上电读一次校验在位；NACK/PartID 错 → 置 PN_SW_ERROR，闭环动作禁启
```

- k 表（按 Span 档）：Span200（±100kPa 型）→ **k=32**；其余档位到货前不引入（单 SKU 纪律）。
- 量程饱和：|P| > 100kPa 的物理输入按传感器行为钳位 ±100（孪生 `SENSOR_SPAN_KPA` 同构）。
- 分时单传感（决策 3）：只测歧管 M 测量位；P2 的 8× 全通道方案留 P2，届时经 TCA9548A。

## 2. 阀/泵 PWM 驱动 — 保持参数表（drive_policy 冻结）

5.0V 轨 PWM 调制驱动 4.5V 额定执行器（判定方向=**防超压**，PWM 只向下调）。
器件真值：F0520D 450mA@4.5V（V1-V8 通道阀 + VS 充气主阀 + VF 排气主阀）、F0520B 300mA@4.5V（VV 真空主阀）、
ZR370-03PM 泵负载 500mA（电压窗全系 4.05~4.95V）。

### 2.1 阀三态驱动表（255 制 | 等效电压@5.0V 轨 | 稳态电流/阀）

| 状态 | 占空比 | 等效电压 | D 阀电流 | B 阀电流 | 时长/语义 |
|---|---|---|---|---|---|
| 吸入 pull-in | **100%** (255) | 5.00V | 0.50A | 0.33A | **≤100ms** 瞬态（+11% vs 额定，吸合最有利） |
| 全开保持 full-open | **90%** (230/255=90.2%) | 4.51V≈额定4.5V | 0.45A | 0.30A | 连续工作态（固件默认保持档） |
| 节能保持 economy | **55%** (140/255=54.9%) | 2.75V | 0.275A | 0.185A | **有意欠压**（保持力<吸合力，行业典型 40~60%）；35kPa 背压下限 BRINGUP 实测，不足升 65~70%；受限/错峰模式用 |
| 关断 | 0% (0) | 0V | 0 | 0 | 确定性关阀（S 语义；R 不清 duty） |

- 固件常量（`pn_core/types.h`）：`PN_HOLD_DEFAULT_DUTY=230`、`PN_HOLD_DEFAULT_DELAY_MS=100`（吸入窗）。
  节能档 55% 经 BLE Config 服务 `pwm_params` 下发，**不作默认**。
- 状态机（`pn_optimize_power`）：开阀 255 → 经 100ms 吸入窗 → 降保持档；关阀重开复位重来。

### 2.2 泵驱动

| 项 | 值 | 依据 |
|---|---|---|
| 占空比上限 | **≤95%** (242/255) | 5.0V 轨 > 4.95V 窗上限，1% 补偿 |
| 软启动互锁 | **≥1 通道阀开启才允许起泵**（0 通道开 → 泵强制 0） | 启动瞬态电流冲击覆盖 + 干泵防护（spec §2.6） |
| 寿命口径 | 3 万次循环（10s 开/5s 停） | 间歇工况与孪生 duty 模型同源 |
| 死头能力 | +120kPa / **-60kPa** | devices.json `pump.pressure_kpa`（孪生 `PUMP_P_MIN_KPA=-60`） |

## 3. 过压互锁（spec §2.6 硬约束）

量化依据：泵死头 +120/-60kPa >> 阀额定 ±45kPa——气路任一密闭段（泵开+通道全关）满压即超阀额定，
**保护只能靠固件闭环**，不靠死点自然限压。

| 参数 | 值 | 动作 |
|---|---|---|
| 闭环工作带 | **±35kPa**（≤+35 / ≥-35，康复工作点 20~30kPa 落在阀额定内） | XGZP 实时监测歧管 M，越带先调泵 PWM |
| 停泵阈值（正压） | **M > +35kPa** → 泵占空比强制 0 + 告警 | 闭环调压不够快时的硬互锁 |
| 真空钳位 | **M < -40kPa** → 泵强制 0 + 告警（由 -50 收紧至 -40） | 阀负压域（F0520D 吸模式 -40kPa 待 BRINGUP 验证） |
| 告警码 | `0x01 OVERLOAD`（母线超限）/ `0x02 OVERPRESSURE`（M>+35）/ `0x04 VACUUM_CLAMP`（M<-40） | 与 `electrical_sim.ALARM_*` 一致；BLE 上报+状态字 bit15 |
| 母线限流 | 适配器档 **3.0A 初值**（BRINGUP 实测后可调 3A/4A/5A） | 超限=受限模式：错峰（并发全开保持≤4 通道）或降节能保持 |

- 闭环调压**强制非可选**：充/吸动作一律带目标压力（G 命令语义），开环仅允许诊断模式。
- P2 可选：50kPa 机械泄压阀作硬件保险冗余（不进 P1.1 BOM）。
- 已知设计盲区（记录在案）：`twin_api.c` 旧超压阈值 120kPa > 传感器量程 100kPa，真机永不触发；
  按本表改为 +35kPa 工作带停泵路径（固件安全层 `pn_check_overpressure` 参数按本表传）。

## 4. 电气场景矩阵（孪生仿真基线，spec §2.7.1）

由 `firmware/twin/electrical_sim.py` 从 devices.json 实时计算（改库即改表）；断言见
`test_electrical_sim.py`（run_tests.sh §2d）。模型：`V_eff = duty×5.0V`，`I = V_eff/R_coil`
（R_coil=4.5V/额定电流：D=10Ω/B=15Ω），90% 保持恰=额定 450mA（registry "等效4.5V=额定"）。

| # | 场景 | 母线电流 | 判定 | 告警 |
|---|---|---|---|---|
| 1 | 单通道充气（V1+S 保持+泵95%） | 1.375A | ✓ ≤3A | — |
| 2 | 单通道吸气（V1+V 保持+泵95%） | 1.225A | ✓ ≤3A | — |
| 3 | 单通道排气（V1+F 保持，泵停） | 0.900A | ✓ ≤3A | — |
| 4 | 单通道保压（V1 节能保持） | 0.275A | ✓ ≤3A | — |
| 5 | 充气吸入瞬态（V1+S 100%≤100ms+泵） | 1.475A | ✓ 瞬态 ≤3A | — |
| 6 | 典型 3 通道充气（V1-3+S 保持+泵95%） | 2.275A | ✓ ≤3A | — |
| 7 | **最坏 9 阀全开保持+泵95%** | **4.525A** | **✗ >3A 受限模式** | `OVERLOAD` + 错峰/节能建议 |
| 8 | 错峰对策：9 阀节能保持+泵95% | 2.950A | ✓ ≤3A | — |
| 9 | 搬气（S+V+V1 保持+泵95%） | 1.675A | ✓ ≤3A | — |
| 10 | 非法工况：0 通道开起泵 | 0.000A | ✓ 互锁拦截（泵强制 0） | —（interlock 标记） |
| 11 | 过压 M=+36kPa | 0.900A | ✓ 停泵路径生效 | `OVERPRESSURE` |
| 12 | 真空钳位 M=-41kPa | 0.750A | ✓ 停泵路径生效 | `VACUUM_CLAMP` |

与本表 4.525A（泵按 95% 占空比 0.475A）同式同源；任务书速算 9×0.45×0.9+0.475≈4.12A 为
占空比直折的保守下界——三者同判 ">3A"，断言方向是**检测并告警**（受限模式），不是回避物理事实。

## 5. 验收断言（TDD，run_tests.sh §2d 全绿）

1. **超限检测与告警**：正常场景全 ≤3.0A 且无告警；最坏场景必检出 + `OVERLOAD` + 可行建议
   （节能保持对策自身须 ≤3A）。
2. **稳态有效电压窗**：全开保持 ∈[4.05,4.95]V；节能保持有意欠压 → ≥2.5V 且标记 `hold_economy`；
   吸入瞬态允许 5.0V 但 ≤100ms。
3. **泵限制**：请求超限被钳 ≤95%；0 通道开启时泵必 0（软启动互锁）。
4. **过压路径**：M>+35kPa 停泵+告警；M<-40kPa 真空钳位停泵+告警。
5. **参数单源**：临时改 devices.json 阀电流（0.45→0.60A）→ 仿真输出随之变（4.525→5.875A），
   字节级复原后回原值。
