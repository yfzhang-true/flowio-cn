## 5. 下单问询项汇总（附聊天框可直接转发）

致荣华冠下单时在订单备注/客服同步以下三条（详版见 `literature/valve-vendor-questionnaire.md`）：

1. F0520D：C 形架翻边（0.7mm）有无安装孔？孔径/孔位尺寸？（支架设计要用）
2. F0520D：通道阀在负压 -40kPa 下可否正常保持关断？（吸模式气路会受负压）
3. F0520B：确认负压专用档（0~-45kPa）；有孔版 ⌀2.0×2 的孔距尺寸？
4. 2P 白壳连接器型号（JST 兼容？可否只发散线？）
5. 3.7V 三型号（F0520D/F0520B/ZR370-03PM-3.7V）完整参数表（与 4.5V 档同格式，问询单 §5 字段清单）。

到货自检兜底（不等商家也能当天定案）：线圈电阻三档判据/NC 吹气确认/卡尺对图——
见 `docs/bringup-checklist.md` §A。
