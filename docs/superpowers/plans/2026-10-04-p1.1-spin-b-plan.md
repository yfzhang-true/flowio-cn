## T1 选型落定 + 数据入库（✅ 阀已定：0520D×8+0520F×1；泵 370 族共通参数先行，A/B 待 1e）
1. 0520D/F 全参数入 `devices.json`（dims 19×19×61 / 21×33×68，placement=EDGE_OUT，
   port.type=pneumatic，气嘴朝向按 1a 形态）；XGZP6897D-C 入库（SURFACE，
   双倒钩 port 朝上——port 模型扩展 dir 三维）；WJ500V 封装 offset 修正；
   **FIT0801 泵入库（官方真值 27×27×58 + ⌀4.3 双气嘴 port，侧口吸/中口出）**。
2. ingest 脚本扩维（port.dir 3D 化）；L5 schema 断言同步。

## T2 原理图增改（v3.2：通道数随 1f，泵路已定）
1. 阀路按 **1f 裁定**：β=11×0520D（8 通道+主阀 S/V/F，Q3-Q13）或 α=8D+1F（Q3-Q13 中 9 路）；
   泵路 FIT0801（Q14：2-pin+SS14 飞轮，PWM 调速，启动 ~1A 裕量）；
   XGZP6897D I2C（TCA9548A 通道 + 0.1µf 去耦 + 上拉）；**电源树 v3（单 5V）**：
   5V/3A 外部适配器入（1d 定 DC005/USB-C 形式）→ 5V 执行器母线直挂 →
   现有 TPS54331 出 3.3V（**删除 12V 支路与新增 buck**）。
2. ERC 0 错；`kicad-cli sch export netlist` 重导 → netlist.py/graph 断言绿。

## T3 PCB：封装 + 布局
1. 阀/传感焊盘 footprint 按手册图手建（s-expr .kicad_pcb 内联，SWIG 一进程一操作）。
2. 五缺陷移件（C9/R3/HD 孔位/双过孔——HD 移位后 case_geom.ST 同步，钻孔对拍验证）。
3. placement_advice 布局：阀排边缘带 + 与 Q3-Q10 同域亲和 + XGZP 近歧管；
   L5 朝向/贴边/匹配断言实时守门。

## T4 布线

5V 执行器母线加宽（8D+F+泵启动峰值 ≈2.1A + 裕量 ≥3A）；KRT 连通性复核。

## T5 制造包重出 + 真值同步
