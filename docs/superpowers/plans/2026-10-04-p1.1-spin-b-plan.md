# Plan: P1.1 一体化改版（T1-T9 · 待用户批准 spec 后执行）

> 分支: p1.1-spin-b · 每任务 TDD/守门（先红后绿；每步 DRC 差分净减不增）· 决策点见 spec §4

## T1 选型落定 + 数据入库（✅ 阀已定：0520D×8+0520F×1，用户 2026-10-04 供 datasheet）
1. 0520D/F 全参数入 `devices.json`（dims 19×19×61 / 21×33×68，placement=EDGE_OUT，
   port.type=pneumatic，气嘴朝向按 1a 形态）；XGZP6897D-C 入库（SURFACE，
   双倒钩 port 朝上——port 模型扩展 dir 三维）；WJ500V 封装 offset 修正。
2. ingest 脚本扩维（port.dir 3D 化）；L5 schema 断言同步。

## T2 原理图增改
1. 9 路阀线圈符号（8×0520D + 1×0520F，2-pin + SS14 飞轮对位，新增 Q13 路）；
   XGZP6897D I2C（TCA9548A 通道 + 0.1µf 去耦 + 上拉）；电源树：DC005 2A 型入
   → 新增 5V/2A buck（阀轨）→ TPS54331 出 3.3V。
2. ERC 0 错；`kicad-cli sch export netlist` 重导 → netlist.py/graph 断言绿。

## T3 PCB：封装 + 布局
1. 阀/传感焊盘 footprint 按手册图手建（s-expr .kicad_pcb 内联，SWIG 一进程一操作）。
2. 五缺陷移件（C9/R3/HD 孔位/双过孔——HD 移位后 case_geom.ST 同步，钻孔对拍验证）。
3. placement_advice 布局：阀排边缘带 + 与 Q3-Q10 同域亲和 + XGZP 近歧管；
   L5 朝向/贴边/匹配断言实时守门。

## T4 布线
freerouting 火力线（-mp 200 -us hybrid -hr 1:1 …）→ 0 未连 → DRC 0 错；
12V 轨加宽（8×~60mA 阀 + 裕量 ≥1A）；KRT 连通性复核。

## T5 制造包重出 + 真值同步
pos/drl/step/netlist 再生 → devices.json refs 对齐 → L5 全绿（新 pneumatic 断言 +
钻孔↔新 ST 对拍）；JLC 工艺复核（线宽/过孔/开槽/板厚）。

## T6 外壳 + 歧管重生成
make_case：气口阵列槽（Ø2 阵列 EDGE_OUT）、阀腔净空（真值高度链）、可能扩板后
整体尺寸；歧管件 make_manifold.py（1 进 8 出 1 测）；L1-L4 全绿（干涉 0.000）。

## T7 孪生 + 站点
make_meshes/make_flows（阀/传感部件入孪生，pneumatic 流光延伸到气口）；
build_site + 双态截图目视。

## T8 全量回归 + 部署
六层全绿（退出码 0）→ main + gh-pages 推送 → 生产终验 → HANDOFF/差距文档更新
（删 LiPo 项）。

## T9 用户交付物
更新后 fab 包 + 阀/歧管采购清单（含渠道）+ 装配注意事项（气路接管图）。

## 依赖与风险
- 阀型号未定（决策点 1）→ T1 阻塞项，其余可先行；

- KiCad footprint 手建需与实物试装核对（首件检查项）。
