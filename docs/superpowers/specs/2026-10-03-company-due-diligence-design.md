## 2. 每家公司尽调维度（天眼查 CLI 6 模块）

| 模块 | CLI 命令 | 尽调问题 |
|---|---|---|
| **过去** | `tyc history historical-overview` | 历史变更（名称/法人/注册资本/股东）——公司是否稳定 |
| **现在·工商** | `tyc company registration-info` | 存续状态/注册资本/实缴/人数/经营范围 |
| **现在·风险** | `tyc risk overview` | 失信/被执行/行政处罚/经营异常/严重违法——有没有坑 |
| **现在·股东** | `tyc company shareholder-info` | 股权结构/实控人——谁说了算 |
| **现在·知产** | `tyc intellectual_property patent-info` + `software-copyright-info` | 专利/软著数量与方向——技术实力验证 |
| **现在·经营** | `tyc operation news-sentiment` + `qualifications` | 舆情/资质/融资——行业地位与口碑 |
| **将来·指标** | 上述数据综合分析 | 成长性/稳定性/INFP 契合度 |

## 3. 分析框架

每家公司产出结构：
```
### 公司名（统一社会信用代码）
#### 基本画像（工商摘要表）
#### 过去：关键变更时间线
#### 现在：风险扫描（✅ 无坑 / ⚠️ 关注 / ❌ 有坑）
#### 现在：技术实力（专利数/软著数/方向）
#### 现在：团队与文化（人数/社保/舆情）
#### 将来：成长性评估
#### INFP 契合度评分（1-10）
#### 建议（投递/观望/跳过）
```
