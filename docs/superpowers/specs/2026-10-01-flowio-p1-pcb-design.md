## 3. 系统架构

```
DC-005 座（5V/3A）──→ SS34 ──────┐
                                 ├──→ 5V 共用轨 ──→ 8× AO3400 → 端子 → 阀×7+泵×1
USB-C VBUS（5V/500mA）→ SS34 ────┘  │
```

### 3.3 电路块明细

#### 3.3.1 电源输入
- DC-005 座（C431533）→ SS34 → 5V 轨（修正 #9：1A 二极管不够 2A+ 峰值）
- USB-C 6P（C456012）→ CC1/CC2 各 5.1kΩ 下拉 → VBUS → SS34 → 5V 轨
- 5V 轨去耦：100µF 陶瓷 ×2 + 100nF ×2（靠近 TPS54331 VIN 和 AO3400 组）

#### 3.3.2 TPS54331DR Buck（5V→3.3V/3A）
- VIN: 5V，EN: 100kΩ 上拉
- L1: CDRH103RNP-6R8NC（C167253）6.8µH/3.84A
- D1: SS34（C8678）3A catch diode
- 反馈: R1=10.0kΩ（上）/ R2=3.24kΩ 1%（下）→ Vref=0.8V → Vout=0.8×(1+10/3.24)=3.27V（修正 #11）
- 补偿: R=10kΩ, C=2.2nF + 22pF
- Boot cap: 0.1µF（PH→BOOT）
- 软启动: 0.1µF（SS→GND）
- 输出: 47µF 陶瓷 ×2 + 100nF ×2
- **布局约束**: PH→SS34→L1 三者 <5mm；输入旁路紧贴 VIN

#### 3.3.3 CH340K USB 转串口（从 3.3V 供电；修正 #10+#12：CH340N→E→K）
- VCC = 3.3V，V3 短接 VCC（手册: 3.3V 模式）
- 内置振荡器——无需外部晶振（CH340N/E/C 系列内置，G 系列才要）
- USB: D+→22Ω→USBLC6→UDP, D-→22Ω→USBLC6→UDM
- TXD→1kΩ→ESP32 RXD(GPIO44)
- RXD←1kΩ←ESP32 TXD(GPIO43)
- 自动下载: SS8050×2 + 10kΩ 基极上拉 ×2 + 1kΩ 串联 ×2
  - DTR# → 1kΩ → SS8050#1 基极（10kΩ 上拉）→ 集电极 → EN
  - RTS# → 1kΩ → SS8050#2 基极（10kΩ 上拉）→ 集电极 → GPIO0

#### 3.3.4 I2C 传感链（5 通道）
- TCA9548APWR（TSSOP-24）@0x70（A0/A1/A2 全接 GND）
- RESET 引脚: 10kΩ 上拉到 3.3V
- 主总线上拉: SDA/SCL 各 4.7kΩ 到 3.3V
- 每通道下海上拉: SDA/SCL 各 10kΩ 到 3.3V（×5 通道 = 10 颗）
- 传感器连接器: XH2.54-4P 侧入（C5359632）×5，线序 VCC/GND/SDA/SCL（丝印标注）
- CH6/CH7 留空，丝印标注"预留"

#### 3.3.5 阀驱动（8 路 AO3400A 直驱）
每路 4 元件:
```
GPIO → 1kΩ → AO3400 栅极
              ├→ 源极 → GND
              └→ 漏极 → WJ500V 端子一端
                   ↑
5V 轨 ── 阀线圈 ──┘ + SS14（阴极→5V，阳极→漏极）
10kΩ 栅极下拉→GND（防浮空=断电阀关闭）
```
- AO3400A ×8（C20917 基础库，SOT-23）
- SS14 ×8（C2480 基础库，SMA）
- WJ500V-5.08-2P 端子 ×8（C8465）

#### 3.3.6 状态指示与用户交互
- WS2812B（GPIO48 经 330Ω）+ 100nF 就近去耦
- PWR LED: 红 0603 + 1kΩ（接 3.3V）
- User LED: 蓝 0603 + 1kΩ（空闲 GPIO）
- TX/RX LED: 黄 0605 ×2 + 1kΩ ×2（从 CH340K TXD/RXD 取信号）
- BOOT 按钮: 6×6mm SMD
- RST 按钮: 6×6mm SMD
- User 按钮: 6×6mm SMD + 10kΩ 上拉

#### 3.3.7 调试/扩展排针
- UART: 4P 排针（TXD/GND/RXD/3.3V）
- GPIO: 4P 排针（空闲GPIO1/3.3V/GND/空闲GPIO2）

## 11. 风险与缓解

| 风险 | 概率 | 缓解 |
|---|---|---|
| TPS54331 布局不当导致不稳定 | 中 | 严格遵循手册 p17 布局指南 |
| 天线净空不够影响 WiFi | 低 | 布局时 15mm 硬约束，模组短边朝外 |
| USB 500mA 不足以供 WiFi 突发 | 低 | 仅 USB 时不开 WiFi（编程模式） |
| AO3400 热设计不足 | 极低 | 最大负载 1A/路 × 50mΩ = 50mW，远低于 1.4W 额定 |
