## 2. 集成设计（当前阶段完成，非 P2）

### 2.1 电磁阀板载（v2 定案 0520D/F；v3.5 增补：实物形态/真尺寸/电流两说兜底）
- **8× 0520D 两通常闭端口阀 + 1× 0520F 两位三通排气总阀**（用户供 datasheet，
  固件/孪生同源既定选型）：通电=充气（外部气源经进气口）、断电=**保压**、
  F 通电=全阵列**统一排气**——充/保/排 三态复刻；
- **3.7V 变体评估（2026-10-05 两轮修正终版·用户查证纠正）**：用户查证 listing SKU 确有
  3.7V 型号（阀/泵均有）——推翻"目录最低 4.5V"的旧论断；同时修正物理论证：共轨 PWM 下
  **轨道电流由功率决定**（2W→400mA@5V），与线圈电压档无关（"+22% 电流"仅对直驱成立）。
  两档 5V 轨真实差异=占空比深度（4.5V→80% / 3.7V→54%）与参数文档化（4.5V 列在规格表、
  3.7V 列缺失无据）。**裁定：P1.1 主 BOM 维持 4.5V**（参数有据+占空比浅+与 5V 轨匹配）；
  **致荣采购单加 3.7V 样品**（F0520D-3.7V×1 + ZR370-03PM-3.7V×1 ≈¥11）——30V/10A 电源
  设 3.7V 实测线圈电阻/吸合/压比，参数补齐后 P2 电池泵模块（1S 锂电直驱免升压）按 3.7V
  选型；若用户改判"电池原生优先"，全 BOM 切 3.7V 以商家补充参数表为前置。
- **实物形态（v3.5 图纸+实物照精读修正，literature/valve-0520df-spec.md §4）**：
  C 形架+红黑引线+2P 白壳连接器（**非 THT 直插**）→ PCB 挂 **11× 2P 卧贴插座**，
  阀体固定印刷支架/歧管（D 用 0.7 翻边、F 选有孔变体 ⌀2.0 孔×2）；
  真尺寸 D≈20×13×13 / F≈15.2×13×17.5（嘴 ⌀3.0~3.5→3mm 管，原 61/68mm 档作废）；
- **电流两说（设计已兜底）**：datasheet 文本 240mA/1.6W（内部不自洽+范文错漏）vs
  档案 D 85mA/F 320mA（商家确认）+ 渠道行业带 18~30Ω（150~250mA，240mA 概率大）
  → **预算按最坏 240mA/只**：β 最坏并发 10 阀=2.4A+泵 0.5A=2.9A<3A ✓；
  关闭：BRINGUP 测线圈电阻（≈19/50/14Ω 三档判据）+ 商家问询单
  （literature/valve-vendor-questionnaire.md，用户转发）；若定案 240mA →
  适配器升 5V/4A 或固件泵软启动互锁（峰值 3.4A 瞬态）+ T6 壳体通风；
- ⚠ **v3.2 发现架构缺口**：此拓扑**做不了每通道真空**（通道口只连充气歧管，无到泵
  吸气口路径），而 Vacuum 是 FlowIO 六动作之一（parity 已承诺）→ 新决策点 **1f**；
- **DFR0866 替代评估=否决**（6V 欠压 70% 功率吸合风险 + 40kPa 压比 < 泵真空 -58kPa +
  3-way 单阀做不全六动作；详见 literature/dfrobot-fit0801-dfr0866-eval.md——
  4.5V 直挂 5V 轨才是零变换复杂度，"电压高=体积大"不成立，压比才是体积主因）；
- 驱动：现有 8 路 AO3400+SS14 复用 + 新增路数随 1f 裁定（α=+1 路，β=+4 路）；
- 5V 阀轨直供（4.5V 额定，5V 下电流 +11% 在规格内）。
- 歧管：3D 打印（1 进 + 8 出 + 1 测量位 + 排气汇集至 F）；
- 气嘴 Φ3.2：3mm 管过盈直插或 JT-709 变径到 4mm（装配指南已有预案）。

### 2.2 压力传感（v3.5 主选切换：XGZP6897D 非-C——淘宝闽芯店在售 SKU，追溯链最短）
- **BOM=XGZP6897D 100KPDPN（非-C）**：I2C **0x6D**、**±2%Span**（略优于 -C 的 ±2.5%FS）、
  24bit、2.5~5.5V、ESD 4kV、过载 2×、待机 100nA；**寄存器手册全收**
  （0x30 CMD 0x0A 组合采集→Sco 轮询→0x06-08 24bit 数据，`P=ADC/k` k 表按 Span 查：
  Span200→k=32；温度/256——`component-registry.md` §3 即驱动规格，T7 直落地）；
- 引脚与 -C 兼容（2=Vdd/6=SDA/7=SCL/8=GND/1-3-4-5 禁连；上拉 4.7k；VDD-GND 0.1µF）；
  几何同族：本体 10.6×7×3.5（总高 9.5 含倒钩）、倒钩 ⌀3.22/孔 ⌀0.9→**3mm 管（阀侧统一）**、
  **P1=高压端接管/P2=低压端大气开放（表压读法）**、焊盘 2.54 节距；
- -C 变体（0x58，`xgzp6897d-c-spec.md` 全档）降为备选；
- TOY0058/BMP180 否决维持（绝对压/无气口/模块形态，`sensor-pressure-eval.md`；
  BMP390 环境基准留 P2）；数量：决策 3（1× 分时推荐）。
- **TOY0058/BMP180 评估=否决（2026-10-05 用户推荐后复核）**：绝对压量程 300~1100hPa
  （+50kPa 表压=1513hPa 超上限 37%）、**无气口**（裸片小孔测环境大气，不能接管）、
  评估模块形态不可入整机——三类硬伤，见 literature/sensor-pressure-eval.md；
  BMP390 裸片环境基准留作 P2 可选项。

### 2.3 供电（v3 大简化：单一 5V，纯外部，无电池）
- **全部执行器同为 5V 系**（阀 4.5V 额定 5V 直供合法 + 泵 370 族 1.5~6V）→
  **删除 12V 支路与新增 buck**：单一 5V/3A 外部适配器 → 5V 执行器母线
  （8D 0.75A + F 0.36A + 泵启动 ~1A，峰值 ≈2.1A）→ 现有 TPS54331 → 3.3V。
- 输入形式（决策点 1d）：DC005 换 5V/3A 型 + USB-C 并存（或门）vs **仅 USB-C PD
  5V/3A 单口**（省一个插座，手机充电头即用——推荐评估）。

### 2.4 微型泵（v3.5 定案：ZR370-03PM，替代 FIT0801——国产淘宝链+充气压一手标注）

  **双顶嘴 ⌀4.2×2（充/吸口固定，反接不换向）**；4.5V 负载 **<500mA**（<2W，

### 2.6 过压防护（v3.5 新增硬约束——ZR370 死头能力 vs 阀额定）
- 量化：ZR370-03PM 死头 **+120kPa/-60kPa** >> F0520 阀额定 **±45kPa**（350mmHg）
  → 气路任一密闭段（泵开+通道全关）即超阀额定；
- **闭环调压强制（非可选）**：XGZP 实时监测歧管 M + 泵 PWM 调速，工作带 **≤+35kPa / ≥-35kPa**
  （康复工作点 20~30kPa 落在阀额定内）；固件互锁：泵运转必须 ≥1 通道阀开启；
  真空钳位由 -50 收紧至 **-40kPa**；XGZP 过压即停泵+告警；
- P2 可选：50kPa 机械泄压阀（硬件保险冗余，B2B 认证叙事加分）。

**国产化追溯（用户 2026-10-05 硬约束）**：阀/泵/传感全部国产+淘宝可购——
致荣华冠（阀/泵/支架/管）、CFSensor 闽芯店（传感）、Kamoer（转接）、JLC（电子料）；
全器件"型号↔店铺↔一手档↔参数↔状态"闭环见 **`docs/component-registry.md`**（单一追溯源）。

### 2.7 数字孪生阶段强制要求（2026-10-05 用户两条提示 → 验收门槛）

**2.7.1 电气驱动仿真层（提示①）**
- 模型：从 devices.json `pneumatic_devices` 读取线圈电流/电压窗/PWM 策略/泵负载——参数单源，
  改库即改仿真（禁双份手抄）；
- 孪生输出：每个气动动作仿真的**母线电流轨迹、各阀有效电压/占空比、瞬时与稳态功率**；
- 场景矩阵（至少）：单通道充/吸/排/保、典型 1-3 通道充气、最坏 9 阀全开保持+泵、
  搬气（S+V+D）、过压工况（M>35kPa 停泵路径）；

  ④过压停泵+告警路径仿真通过；⑤场景矩阵全跑无异常。

## 3. 板面与结构影响（决策 2 已定：倾向微扩 ~100×80，T3 试摆终定）
