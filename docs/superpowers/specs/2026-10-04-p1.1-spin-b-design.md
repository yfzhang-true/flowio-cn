## 2. 集成设计（当前阶段完成，非 P2）

### 2.1 电磁阀板载（v2 定案 0520D/F；v3.5 增补：实物形态/真尺寸/电流两说兜底）
- **8× 0520D 两通常闭端口阀 + 1× 0520F 两位三通排气总阀**（用户供 datasheet，
  固件/孪生同源既定选型）：通电=充气（外部气源经进气口）、断电=**保压**、
  F 通电=全阵列**统一排气**——充/保/排 三态复刻；
- **实物形态（v3.5 图纸+实物照精读修正，literature/valve-0520df-spec.md §4）**：
  C 形架+红黑引线+2P 白壳连接器（**非 THT 直插**）→ PCB 挂 **11× 2P 卧贴插座**，
  阀体固定印刷支架/歧管（D 用 0.7 翻边、F 选有孔变体 ⌀2.0 孔×2）；
  真尺寸 D≈20×13×13 / F≈15.2×13×17.5（嘴 ⌀3.0~3.5→3mm 管，原 61/68mm 档作废）；
- **电流两说（设计已兜底）**：datasheet 文本 240mA/1.6W（内部不自洽+范文错漏）vs
  档案 D 85mA/F 320mA（商家确认）+ 渠道行业带 18~30Ω（150~250mA，240mA 概率大）
  → **预算按最坏 240mA/只**：β 最坏并发 10 阀=2.4A+泵 0.5A=2.9A<3A ✓；
  关闭：BRINGUP 测线圈电阻（≈19/50/14Ω 三档判据）+ 商家问询单
  （literature/valve-vendor-questionnaire.md，用户转发）；若定案 240mA →
  适配器升 5V/4A 或固件泵软启动互锁（峰值 3.4A 瞬态）+ T6 壳体通风；
- ⚠ **v3.2 发现架构缺口**：此拓扑**做不了每通道真空**（通道口只连充气歧管，无到泵
  吸气口路径），而 Vacuum 是 FlowIO 六动作之一（parity 已承诺）→ 新决策点 **1f**；
- **DFR0866 替代评估=否决**（6V 欠压 70% 功率吸合风险 + 40kPa 压比 < 泵真空 -58kPa +
  3-way 单阀做不全六动作；详见 literature/dfrobot-fit0801-dfr0866-eval.md——
  4.5V 直挂 5V 轨才是零变换复杂度，"电压高=体积大"不成立，压比才是体积主因）；
- 驱动：现有 8 路 AO3400+SS14 复用 + 新增路数随 1f 裁定（α=+1 路，β=+4 路）；
- 5V 阀轨直供（4.5V 额定，5V 下电流 +11% 在规格内）。
- 歧管：3D 打印（1 进 + 8 出 + 1 测量位 + 排气汇集至 F）；
- 气嘴 Φ3.2：3mm 管过盈直插或 JT-709 变径到 4mm（装配指南已有预案）。

### 2.2 压力传感（v3.5 主选切换：XGZP6897D 非-C——淘宝闽芯店在售 SKU，追溯链最短）
- **BOM=XGZP6897D 100KPDPN（非-C）**：I2C **0x6D**、**±2%Span**（略优于 -C 的 ±2.5%FS）、
  24bit、2.5~5.5V、ESD 4kV、过载 2×、待机 100nA；**寄存器手册全收**
  （0x30 CMD 0x0A 组合采集→Sco 轮询→0x06-08 24bit 数据，`P=ADC/k` k 表按 Span 查：
  Span200→k=32；温度/256——`component-registry.md` §3 即驱动规格，T7 直落地）；
- 引脚与 -C 兼容（2=Vdd/6=SDA/7=SCL/8=GND/1-3-4-5 禁连；上拉 4.7k；VDD-GND 0.1µF）；
  几何同族：本体 10.6×7×3.5（总高 9.5 含倒钩）、倒钩 ⌀3.22/孔 ⌀0.9→**3mm 管（阀侧统一）**、
  **P1=高压端接管/P2=低压端大气开放（表压读法）**、焊盘 2.54 节距；
- -C 变体（0x58，`xgzp6897d-c-spec.md` 全档）降为备选；
- TOY0058/BMP180 否决维持（绝对压/无气口/模块形态，`sensor-pressure-eval.md`；
  BMP390 环境基准留 P2）；数量：决策 3（1× 分时推荐）。
- **TOY0058/BMP180 评估=否决（2026-10-05 用户推荐后复核）**：绝对压量程 300~1100hPa
  （+50kPa 表压=1513hPa 超上限 37%）、**无气口**（裸片小孔测环境大气，不能接管）、
  评估模块形态不可入整机——三类硬伤，见 literature/sensor-pressure-eval.md；
  BMP390 裸片环境基准留作 P2 可选项。

### 2.3 供电（v3 大简化：单一 5V，纯外部，无电池）
- **全部执行器同为 5V 系**（阀 4.5V 额定 5V 直供合法 + 泵 370 族 1.5~6V）→
  **删除 12V 支路与新增 buck**：单一 5V/3A 外部适配器 → 5V 执行器母线
  （8D 0.75A + F 0.36A + 泵启动 ~1A，峰值 ≈2.1A）→ 现有 TPS54331 → 3.3V。
- 输入形式（决策点 1d）：DC005 换 5V/3A 型 + USB-C 并存（或门）vs **仅 USB-C PD
  5V/3A 单口**（省一个插座，手机充电头即用——推荐评估）。

### 2.4 微型泵（v3.5 定案：ZR370-03PM，替代 FIT0801——国产淘宝链+充气压一手标注）
- 1× **ZR370-03PM**（致荣华冠，用户供全档）：有刷隔膜 **⌀24 泵头×58.1 总长**、
  **双顶嘴 ⌀4.2×2（充/吸口固定，反接不换向）**；4.5V 负载 **<500mA**（<2W，
  电压范围 4.05~4.95V→固件 PWM 上限 ~95%）；**充 +120kPa / 吸 -60kPa**、≥2.8LPM、
  <60dB（垫海绵）、60g、寿命 3 万次循环（10s/5s 间歇=duty 模型同源）；
- 安装：**致荣硅胶支架**（环 ID23 配 ⌀24 头，脚距 46mm M3）×2 前后夹持——
  免自研软垫座，减振+固定一体（literature/硅胶支架.pdf）；
- 驱动：+1 路 Q14 AO3400+SS14，PWM 调速；**过压防护见 §2.6（泵死头 120kPa>>阀额定）**；
- 档案：`ZR370-03PM.pdf`；FIT0801/ZR370-02PM 降为参考（`component-registry.md` §2）。

### 2.5 原版官方图解对照（2026-10-05 用户供图精读，详见 docs/flowio-parity-gap.md §1b）
- **爆炸图=两套装配栈**：泵模块独立（壳+驱动板+微泵+电池+底座）；主模块=顶壳(5 气口)
  → MCU 独立小板 → 主驱动板（**阀排+硅管+压力传感板载**）→ LiPo 薄层 → 底座；
- **本 spec 三大方向获原版铁证**：①阀装板上+管路可视+顶部气口阵列（=1a 竖装同源）；
  ②泵自成一体的"源"单元（我们等价集成=泵舱+Q14 驱动，且单泵充吸两用覆盖 S/M 分档语义）；
  ③六动作语义（充/吸/泄/保/测/变速）10 通道全覆盖；
- **显式取舍**：原版模块化（泵分体、MCU 小板、电池层）→ 我们一体化单板单盒
  （B2B 开箱即用；ESP32-S3 单板省一层；无电池=用户明确要求）——模块化留 P2 生态位。

### 2.6 过压防护（v3.5 新增硬约束——ZR370 死头能力 vs 阀额定）
- 量化：ZR370-03PM 死头 **+120kPa/-60kPa** >> F0520 阀额定 **±45kPa**（350mmHg）
  → 气路任一密闭段（泵开+通道全关）即超阀额定；
- **闭环调压强制（非可选）**：XGZP 实时监测歧管 M + 泵 PWM 调速，工作带 **≤+35kPa / ≥-35kPa**
  （康复工作点 20~30kPa 落在阀额定内）；固件互锁：泵运转必须 ≥1 通道阀开启；
  真空钳位由 -50 收紧至 **-40kPa**；XGZP 过压即停泵+告警；
- P2 可选：50kPa 机械泄压阀（硬件保险冗余，B2B 认证叙事加分）。

**国产化追溯（用户 2026-10-05 硬约束）**：阀/泵/传感全部国产+淘宝可购——
致荣华冠（阀/泵/支架/管）、CFSensor 闽芯店（传感）、Kamoer（转接）、JLC（电子料）；
全器件"型号↔店铺↔一手档↔参数↔状态"闭环见 **`docs/component-registry.md`**（单一追溯源）。

## 3. 板面与结构影响（决策点 2 相关）
阀体尺寸约 17×14×24mm/只（S070 级）× 8 排列 + 歧管 → 90×75 板容纳不下：
- **方案 A（推荐）**：板扩至 ~120×100，阀全内嵌，盖上开气口阵列 + 歧管接口槽；
- **方案 B**：板不扩，阀排做成外挂模组（排针/磁吸 + 软管，FlowIO 泵模块式）。
两方案的 L1-L5 断言集相同（阀=EDGE_OUT+pneumatic+与驱动同域）。

## 4. 决策点（v2：点 1 已由用户供 datasheet 解决，新增 1a/1b/1c）
1. ✅ **阀选型落定（2026-10-04 用户提供数据手册）**：**0520D×8（两通常闭端口阀）+
   0520F×1（三通排气总阀）**，惠州百乘，4.5V 额定/5V 直供合法（+11% 电流在规格内）。
   固件与孪生本就按此建模（-53.3kPa/NC/内漏/保压节能均已入孪生，2026-09-23 归档
   `literature/valve-0520df-spec.md`，含商家确认 NC 证据链）。D=19×19×61mm，
   F=21×33×68mm，气嘴 Φ3.2（配 3mm 管或 JT-709 变径）。派生子决策：
   - **1a 安装形态**：竖装（板上立式 2×4 阵列 76×38mm，免扩板，壳高≈75mm，
     结构简单，**推荐 P1.1**）vs 横装（定制歧管横躺，壳≈35mm，FlowIO 式扁壳，
     歧管复杂，留 P2）；
   - **1b 通道映射**：**9 路=8D+1F（推荐；加 Q13 一路驱动）** vs 8 路（7 通道+1F）。
     注：无 F 则无放气路径（D 断电=关闭非排气）；
   - **1c 电源树（v3 简化）**：✅ 单一 5V/3A 方案定案（删 12V 与新增 buck）；
     子决策 **1d 输入形式**（v3 器件级已核）：
     **B 仅 USB-C = C165948 TYPE-C-31-M-12（5A/20V，Rd 5.1k 取 5V/3A，推荐）** vs
     A DC 圆口 = C720575 DC-044A-A200（3A/30V，体高 7.2 槽带收窄）vs
     C 两者并存（需防倒灌）——现 J1 C431533 仅 500mA **必须换型**（缺陷 #6）；
   - **1e 泵 370 细分（v3.2 消解）**：✅ 采用 FIT0801 官方件，无 A/B 命名问题（§2.4）；
   - **1f 阀架构（v3.2 新增，FIT0801 双口引出）**：
     **β 公共歧管 11×0520D 单型号（推荐）**：每通道 1×D + 三主阀 S(泵出口↔M)/
     V(泵吸气口↔M)/F(M↔大气)——六动作全通（含每通道真空 ✓），单歧管 8+3 口，
     1.04A 阀+0.5A 泵，附赠"单泵搬气"（V+S 同开=B 通道排气直喂 A 通道充气）；
     固件约束：泵只在 S/V 开时运转、真空钳位 ≥-50kPa（0520D 额定 -53.3 < 泵 -58）；
     **α 维持现案 8D+1F**：少 2 只阀，但**无每通道真空**（不符 parity 六动作承诺）；
     γ 每通道 3-way（8×0520F 级）：全动作但 2.84A 阀层爆预算，否决；
   - **1g 阀轻量化复核（v3.3，已结案）**：**0520 系即微型阀效率甜点，本版维持**——
     ①更轻档查证：DFR0866 已三否决；JF-0530B 系推拉电磁铁非流体阀；0403 血压计小阀
     行业典型 0.8~2W 反更耗电；②减重最大杠杆是阀数量（α 比 β 少 2 只 ≈ -30g）；
     ③轻量档无一手 datasheet → P2 紧凑版调研（该结论按致荣 F0520D 450mA 实测复核）；
   - **1i 阀源（v3.5 新增·国产化追溯配套）**：
     **a 致荣华冠 F0520D×10 + F0520B×1（推荐）**——文档最全（用户供全档）、与泵/支架/
     硅胶管/转接同店生态、D=NC 通用 450mA + B=负压专用 NC 300mA 各守其域；
     代价：450mA → **PWM 保持强制**（吸入 100%→保持 ~55%，9 阀并发保持 ≈2.25A+泵 0.5A ✓）；
     **b 惠州百乘 0520D/F**——240mA/320mA 更省电，但 datasheet 潦草、问询中；
     待商户问询单/BRINGUP 线圈电阻定案后可切换（两者引线+2P 连接器形态一致，BOM 兼容）；
   - **1h 产品形态（v3.4 新增·用户提出·**当前阻塞点**）：分装式（跟原版 FlowIO：
     主模块 + 独立泵模块）vs 一体化（当前 §2.4 泵舱方案）**；
     **推荐分装式**——本架构泵本就"软管连接+独立减振、不上板"，
     分装只是把泵舱从主壳移入独立小盒：**哑泵方案**（电机 2 线回主板 Q14 驱动，
     气路 2 管 接 S/V 主阀外侧，泵模块内可选并一枚缓冲电容）→ **PCB/固件零改动**；
     收益：主壳显著缩小（泵舱外移）、有刷泵单独可换、P2 泵模块分档
     （更大/无刷/更高压）不动主板、振动噪声物理隔离更彻底、
     对齐"FlowIO 中国版"平台生态叙事（用户定位：平台而非康复手套整机）；
     代价：+泵模块壳/2×快插气口/JST 2P/软管 ~¥15、T6 拆主壳+泵壳两件、孪生双体渲染；
2. **板面方案**：随 1a 联动——竖装则 2×4 阵列嵌现板尺寸附近（或微扩至 ~100×90）；
   横装则板侧留歧管接口区。
3. **压力传感数量（v3.3 补权衡分析，literature/sensor-pressure-eval.md §5）**：
   **1× 分时（歧管测量位，推荐 P1.1）**：D_i 开时 M 压=活动通道压，顺序控制循环够用；
   1 只传感+无 mux+气路单引出点，FlowIO 同构。短板：D_i 关断（保压）时手套侧不可见、
   无多通道同读、单点故障全盲。
   **8× 并行（每通道手套侧 + TCA9548A）**：逐指连续监测=漏气/爆管/过压报警 +
   保压态反馈 + 真多通道并行闭环 + 传感器冗余——B2B 医疗安全卖点；代价 ~¥170 BOM、
   8×(SOIC8+倒钩让位) PCB 面积、8 引出点装配/泄漏面、逐只偏移校准（出厂标定入 NVS）。
   扫描速度无瓶颈（1ms/通道）。**推荐：P1.1 用 1×，P2 医疗安全版升 8×。**
4. ✅ **端子高度终裁 14.0mm**（JLC 属性 14.07 + 型号尾缀 14-00A 双源一致；
   用户可在 LCSC 页面复核图纸，复核结果优先）。

## 5. 全链验收标准（一件不留）

钻孔↔铜柱对拍）→ devices.json 增补阀/传感条目 → **L1-L5 全绿**（含新 pneumatic

manufacturability 复核（JLC 工艺参数：最小线宽/过孔/开槽）。
