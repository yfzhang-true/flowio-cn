## 2. 集成设计（当前阶段完成，非 P2）

### 2.1 电磁阀板载（对标 FlowIO 主模块 7 阀歧管）
- **8× 常闭微型电磁阀**（12V，与现有 8 路 AO3400 驱动一一对应）；
- 驱动链**零新增**：Q3-Q10 MOSFET + SS14 飞轮二极管 D4-D11 已在 BOM（原设计即为感性负载准备）；
- 歧管：3D 打印集成流道（1 进气 + 8 出 + 1 测量位），材料与外壳同打；
- 气口：Ø2 快插，EDGE_OUT 同侧阵列（新 port.type=pneumatic，槽位匹配自动验证）。

### 2.2 压力传感（选型已定）
- **XGZP6897D-C**（本地数据手册已核）：SOIC8 双倒钩管、I2C 0x58、2.7~5.5V、
  -100kPa~200kPa、DPN 正负压型可选；挂 TCA9548A 通道，倒钩管朝上接管至歧管测量位。

### 2.3 供电（纯外部，无电池）
- DC005 **12V 主输入**（阀排直供 12V 轨）+ USB-C 5V 辅助（调试/供电冗余）；
- TPS54331 buck 12V→3.3V（现有）；**删除一切电池/充电相关条目**（差距文档同步更新）。

## 3. 板面与结构影响（决策点 2 相关）
阀体尺寸约 17×14×24mm/只（S070 级）× 8 排列 + 歧管 → 90×75 板容纳不下：
- **方案 A（推荐）**：板扩至 ~120×100，阀全内嵌，盖上开气口阵列 + 歧管接口槽；
- **方案 B**：板不扩，阀排做成外挂模组（排针/磁吸 + 软管，FlowIO 泵模块式）。
两方案的 L1-L5 断言集相同（阀=EDGE_OUT+pneumatic+与驱动同域）。

## 4. 决策点（请审查裁定）
1. **阀型号/渠道**：LCSC 不售气动件。候选：SMC S070B（12V 常闭 ~17×14×23.5mm，
   Ø2 快插，原版 FlowIO 同源思路，约 ¥25-40/只）／JUKA 迷你 2 位阀（更大更廉）／
   其它。**需要你确认供应商与型号**（这正是"让用户帮忙确认信息源"的场景）。
2. **板面方案**：A 扩板内嵌（推荐）vs B 外挂模组。
3. **压力传感数量**：1× 分时（歧管多路切换测量，FlowIO 式，推荐）vs 8× 并行。
4. **端子高度终裁**：接受 JLC 属性+型号编码双源结论 14.0mm（或你在 LCSC 页面
   顺手复核 datasheet 图纸，复核结果为准）。

## 5. 全链验收标准（一件不留）
ERC 0 错 → DRC 0 错 → freerouting 0 未连 → fab 包重出（pos/drl/step/netlist 再生，
钻孔↔铜柱对拍）→ devices.json 增补阀/传感条目 → **L1-L5 全绿**（含新 pneumatic
断言）→ 外壳/歧管重生成（布尔干涉 0.000）→ 孪生/站点重部署（双态目视）→
manufacturability 复核（JLC 工艺参数：最小线宽/过孔/开槽）。
