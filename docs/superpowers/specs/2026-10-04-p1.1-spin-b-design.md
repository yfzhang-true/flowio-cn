## 2. 集成设计（当前阶段完成，非 P2）

### 2.1 电磁阀板载（v2 定案：0520D×8 + 0520F×1，惠州百乘）
- **8× 0520D 两通常闭端口阀 + 1× 0520F 两位三通排气总阀**（用户供 datasheet，
  固件/孪生同源既定选型）：通电=充气（外部气源经进气口）、断电=**保压**、
  F 通电=全阵列**统一排气**——完整复刻 FlowIO 三态语义；
- 驱动：现有 8 路 AO3400+SS14 复用 + **新增 1 路（Q13+SS14+栅阻）= 9 通道**；
- 5V 阀轨直供（4.5V 额定，5V 下电流 +11% 在规格内）；峰值 ~1.1A；
- 歧管：3D 打印（1 进 + 8 出 + 1 测量位 + 排气汇集至 F）；
- 气嘴 Φ3.2：3mm 管过盈直插或 JT-709 变径到 4mm（装配指南已有预案）。

### 2.2 压力传感（选型已定）
- **XGZP6897D-C**（本地数据手册已核）：SOIC8 双倒钩管、I2C 0x58、2.7~5.5V、
  -100kPa~200kPa、DPN 正负压型可选；挂 TCA9548A 通道，倒钩管朝上接管至歧管测量位。

### 2.3 供电（纯外部，无电池）
- DC005 **12V/2A 主输入**（换 2A 型，现 500mA 型不够）→ 新增 5V/2A buck 作阀轨；
- USB-C 5V 辅助（调试/冗余，二极管或门保留）；
- 现有 TPS54331 出 3.3V（逻辑）；**删除一切电池/充电相关条目**（差距文档同步更新）。

## 3. 板面与结构影响（决策点 2 相关）
阀体尺寸约 17×14×24mm/只（S070 级）× 8 排列 + 歧管 → 90×75 板容纳不下：
- **方案 A（推荐）**：板扩至 ~120×100，阀全内嵌，盖上开气口阵列 + 歧管接口槽；
- **方案 B**：板不扩，阀排做成外挂模组（排针/磁吸 + 软管，FlowIO 泵模块式）。
两方案的 L1-L5 断言集相同（阀=EDGE_OUT+pneumatic+与驱动同域）。

## 4. 决策点（v2：点 1 已由用户供 datasheet 解决，新增 1a/1b/1c）
1. ✅ **阀选型落定（2026-10-04 用户提供数据手册）**：**0520D×8（两通常闭端口阀）+
   0520F×1（三通排气总阀）**，惠州百乘，4.5V 额定/5V 直供合法（+11% 电流在规格内）。
   固件与孪生本就按此建模（-53.3kPa/NC/内漏/保压节能均已入孪生，2026-09-23 归档
   `literature/valve-0520df-spec.md`，含商家确认 NC 证据链）。D=19×19×61mm，
   F=21×33×68mm，气嘴 Φ3.2（配 3mm 管或 JT-709 变径）。派生子决策：
   - **1a 安装形态**：竖装（板上立式 2×4 阵列 76×38mm，免扩板，壳高≈75mm，
     结构简单，**推荐 P1.1**）vs 横装（定制歧管横躺，壳≈35mm，FlowIO 式扁壳，
     歧管复杂，留 P2）；
   - **1b 通道映射**：**9 路=8D+1F（推荐；加 Q13 一路驱动）** vs 8 路（7 通道+1F）。
     注：无 F 则无放气路径（D 断电=关闭非排气）；
   - **1c 电源树**：12V 适配器入（DC005 换 2A 型；现 500mA 型不够）→ 新增
     5V/2A buck 阀轨（8×94mA+F 356mA 峰值≈1.1A）→ 现有 TPS54331 出 3.3V。
2. **板面方案**：随 1a 联动——竖装则 2×4 阵列嵌现板尺寸附近（或微扩至 ~100×90）；
   横装则板侧留歧管接口区。
3. **压力传感数量**：**1× 分时（歧管测量位+多路切换，FlowIO 式，推荐）** vs 8× 并行。
4. ✅ **端子高度终裁 14.0mm**（JLC 属性 14.07 + 型号尾缀 14-00A 双源一致；
   用户可在 LCSC 页面复核图纸，复核结果优先）。

## 5. 全链验收标准（一件不留）
ERC 0 错 → DRC 0 错 → freerouting 0 未连 → fab 包重出（pos/drl/step/netlist 再生，
钻孔↔铜柱对拍）→ devices.json 增补阀/传感条目 → **L1-L5 全绿**（含新 pneumatic
断言）→ 外壳/歧管重生成（布尔干涉 0.000）→ 孪生/站点重部署（双态目视）→
manufacturability 复核（JLC 工艺参数：最小线宽/过孔/开槽）。
