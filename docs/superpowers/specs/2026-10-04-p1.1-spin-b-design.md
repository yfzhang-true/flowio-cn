## 2. 集成设计（当前阶段完成，非 P2）

### 2.1 电磁阀板载（v2 定案：0520D×8 + 0520F×1，惠州百乘）
- **8× 0520D 两通常闭端口阀 + 1× 0520F 两位三通排气总阀**（用户供 datasheet，
  固件/孪生同源既定选型）：通电=充气（外部气源经进气口）、断电=**保压**、
  F 通电=全阵列**统一排气**——完整复刻 FlowIO 三态语义；
- 驱动：现有 8 路 AO3400+SS14 复用 + **新增 1 路（Q13+SS14+栅阻）= 9 通道**；
- 5V 阀轨直供（4.5V 额定，5V 下电流 +11% 在规格内）；峰值 ~1.1A；
- 歧管：3D 打印（1 进 + 8 出 + 1 测量位 + 排气汇集至 F）；
- 气嘴 Φ3.2：3mm 管过盈直插或 JT-709 变径到 4mm（装配指南已有预案）。

### 2.2 压力传感（选型已定）
- **XGZP6897D-C**（本地数据手册已核）：SOIC8 双倒钩管、I2C 0x58、2.7~5.5V、
  -100kPa~200kPa、DPN 正负压型可选；挂 TCA9548A 通道，倒钩管朝上接管至歧管测量位。

### 2.3 供电（v3 大简化：单一 5V，纯外部，无电池）
- **全部执行器同为 5V 系**（阀 4.5V 额定 5V 直供合法 + 泵 370 族 1.5~6V）→
  **删除 12V 支路与新增 buck**：单一 5V/3A 外部适配器 → 5V 执行器母线
  （8D 0.75A + F 0.36A + 泵启动 ~1A，峰值 ≈2.1A）→ 现有 TPS54331 → 3.3V。
- 输入形式（决策点 1d）：DC005 换 5V/3A 型 + USB-C 并存（或门）vs **仅 USB-C PD
  5V/3A 单口**（省一个插座，手机充电头即用——推荐评估）。

### 2.4 微型气泵 370 板载（v3 新增，一手资料已核 `literature/pump-370AB-spec.md`）
- 1× **"370 直流充吸两用真空泵"**（用户套装实泵：顶部双气嘴 ⌀3.6×8.8mm = 充气口+吸气口，
  **单泵覆盖 FlowIO 正压+负压双语义，无需双泵**）；
- **几何真值（listing 参数图直读）**：总长 58mm，泵头 ⌀27.4×27mm，电机 ⌀24×31mm，
  入库 dims=27.4×27.4×58、port 双嘴朝上 exit_z≈35.8——**与 FIT0801 档案（⌀4.3 单嘴）
  是不同变体，FIT0801 只作同族电气参考**；
- 驱动：+1 路 Q14 AO3400+SS14+栅阻，PWM（25kHz ledc）调速；启动 ~1A 已计入 5V/3A 轨；
- 管路：泵双嘴 ⌀3.6 → 4mm 管；阀 Φ3.2 → 3mm 管；变径在歧管内部消化（T6 输入）；
- **细分型号（1e，已简化）**：A=正压充气型（血压计）/B=负压抽气型（吸奶器，充吸两用）
  ——本泵按"充吸两用型"下单即等价 B 系；A/B 商家命名仅影响 BOM 名与孪生微调，
  厂商一手参数表公开网不可得（威力兹官网停摆），**到单前请卖家在订单备注确认**
  （不阻塞设计）；孪生 PUMP_P_MIN_KPA=-58（保守沿用同族下限）；
- 有刷不宜连续运转 → 固件 PWM+间歇策略（孪生已有 duty 模型）。

### 2.5 原版官方图解对照（2026-10-05 用户供图精读，详见 docs/flowio-parity-gap.md §1b）
- **爆炸图=两套装配栈**：泵模块独立（壳+驱动板+微泵+电池+底座）；主模块=顶壳(5 气口)
  → MCU 独立小板 → 主驱动板（**阀排+硅管+压力传感板载**）→ LiPo 薄层 → 底座；
- **本 spec 三大方向获原版铁证**：①阀装板上+管路可视+顶部气口阵列（=1a 竖装同源）；
  ②泵自成一体的"源"单元（我们等价集成=泵舱+Q14 驱动，且单泵充吸两用覆盖 S/M 分档语义）；
  ③六动作语义（充/吸/泄/保/测/变速）10 通道全覆盖；
- **显式取舍**：原版模块化（泵分体、MCU 小板、电池层）→ 我们一体化单板单盒
  （B2B 开箱即用；ESP32-S3 单板省一层；无电池=用户明确要求）——模块化留 P2 生态位。

## 3. 板面与结构影响（决策点 2 相关）
阀体尺寸约 17×14×24mm/只（S070 级）× 8 排列 + 歧管 → 90×75 板容纳不下：
- **方案 A（推荐）**：板扩至 ~120×100，阀全内嵌，盖上开气口阵列 + 歧管接口槽；
- **方案 B**：板不扩，阀排做成外挂模组（排针/磁吸 + 软管，FlowIO 泵模块式）。
两方案的 L1-L5 断言集相同（阀=EDGE_OUT+pneumatic+与驱动同域）。

## 4. 决策点（v2：点 1 已由用户供 datasheet 解决，新增 1a/1b/1c）
1. ✅ **阀选型落定（2026-10-04 用户提供数据手册）**：**0520D×8（两通常闭端口阀）+
   0520F×1（三通排气总阀）**，惠州百乘，4.5V 额定/5V 直供合法（+11% 电流在规格内）。
   固件与孪生本就按此建模（-53.3kPa/NC/内漏/保压节能均已入孪生，2026-09-23 归档
   `literature/valve-0520df-spec.md`，含商家确认 NC 证据链）。D=19×19×61mm，
   F=21×33×68mm，气嘴 Φ3.2（配 3mm 管或 JT-709 变径）。派生子决策：
   - **1a 安装形态**：竖装（板上立式 2×4 阵列 76×38mm，免扩板，壳高≈75mm，
     结构简单，**推荐 P1.1**）vs 横装（定制歧管横躺，壳≈35mm，FlowIO 式扁壳，
     歧管复杂，留 P2）；
   - **1b 通道映射**：**9 路=8D+1F（推荐；加 Q13 一路驱动）** vs 8 路（7 通道+1F）。
     注：无 F 则无放气路径（D 断电=关闭非排气）；
   - **1c 电源树（v3 简化）**：✅ 单一 5V/3A 方案定案（删 12V 与新增 buck）；
     子决策 **1d 输入形式**（v3 器件级已核）：
     **B 仅 USB-C = C165948 TYPE-C-31-M-12（5A/20V，Rd 5.1k 取 5V/3A，推荐）** vs
     A DC 圆口 = C720575 DC-044A-A200（3A/30V，体高 7.2 槽带收窄）vs
     C 两者并存（需防倒灌）——现 J1 C431533 仅 500mA **必须换型**（缺陷 #6）；
   - **1e 泵 370 细分（v3 已简化）**：✅ 单只"充吸两用"泵覆盖正负压（见 §2.4），
     BOM 下单名请卖家按 listing 标注 A/B 确认即可，不阻塞设计；
2. **板面方案**：随 1a 联动——竖装则 2×4 阵列嵌现板尺寸附近（或微扩至 ~100×90）；
   横装则板侧留歧管接口区。
3. **压力传感数量**：**1× 分时（歧管测量位+多路切换，FlowIO 式，推荐）** vs 8× 并行。
4. ✅ **端子高度终裁 14.0mm**（JLC 属性 14.07 + 型号尾缀 14-00A 双源一致；
   用户可在 LCSC 页面复核图纸，复核结果优先）。

## 5. 全链验收标准（一件不留）
ERC 0 错 → DRC 0 错 → freerouting 0 未连 → fab 包重出（pos/drl/step/netlist 再生，
钻孔↔铜柱对拍）→ devices.json 增补阀/传感条目 → **L1-L5 全绿**（含新 pneumatic
断言）→ 外壳/歧管重生成（布尔干涉 0.000）→ 孪生/站点重部署（双态目视）→
manufacturability 复核（JLC 工艺参数：最小线宽/过孔/开槽）。
