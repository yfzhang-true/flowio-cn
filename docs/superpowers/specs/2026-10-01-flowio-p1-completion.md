## 2. 现状逐条根因映射（诊断已核实，坐标 mm）

### 2.1 一处坏过孔 = 6 条违规（先删）

`+5V 过孔 @(78.3649, 60.5)`：同时命中 4×hole_clearance（对 D10.1 焊盘孔边距 0.078）、1×via_dangling、1×unconnected。
它是 route_pcb 阶段 1.5 的手工电源过孔残留，位置紧贴 D10（+5V 肖特基）与 HD 安装孔。
**处理**：删除；在 D10.1 附近用全障碍感知搜索放新 +5V 过孔（落点必须在 In2 +5V 底带 y53-74.5 内）。

### 2.2 孔间距剩余 2 条

### 2.4 未连接 17 条按网络分组

**+3V3 尾巴 (5)**：C13.1(54.7,17.5)、TP1(58.5,21.5)、R29.1(62,30.8)、C12.1(79.2,25.5)——各补"短走线+过孔"落 In2 3V3 区；J6.1 的 +3V3 过孔(88.0,28.69)悬空——诊断其 In2 落点是否在 J6 插件孔的填充让位洞里，是则移过孔到实心填充处。

**GND 尾巴 (4)**：U2.2(TCA, 71.1,47.0)、U5.2(USBLC6, 74.5,13.1)、C17 走线端(16.5,23.6)、C3 走线端(24.4,49.5)——各补"短走线+GND 过孔"下 In1 全板面。

**+5V 尾巴 (1)**：C15.1 走线端(33.2,52.3)——过孔落 In2 +5V B 块(19-36, 28-55)。

**平面孤岛 (7)**：
- In2 +3V3 孤岛区(19.7,21.5)：顶带(y0.8-20.8)与下 L 块(y20.8+)只"边贴边"不重叠，同网不同 zone 对象填充不并合 → 加跨缝同网桥接 zone（矩形，两侧各压 0.4mm）
- In2 +5V B 块(19.7,28.5)：与 A 块在 x=19 贴边 → 同法桥接（若诊断发现实为填充碎片，改为过孔缝合）
- GND zone×4 @(0.5,0.5)：F.Cu 填充存在无过孔孤岛 → 孤岛自动检测（逐 outline 点包含测试找岛内无 GND 过孔者）+ 岛内净空点放缝合过孔下 In1

## 3. 修复策略决策

| # | 决策 | 理由 |
|---|---|---|
| C1 | **脚本修复，不用 GUI** | 既有"一进程一操作"模式已验证（SWIG Remove 后查询失效规避）；每步 DRC 验证闭环；GUI 无法无头运行 |
| C2 | 过孔落点必须**全障碍感知**：焊盘(含孔径)+走线(分段距离-半宽)+过孔+NPTH，间距≥0.2mm | 教训：阶段 1.5 只查焊盘的手工过孔引发 14 条新违规 |
| C3 | 删除类与新建类**分进程**执行 | 同 C1 |
| C4 | 每任务后 `ZONE_FILLER` 重灌 + `kicad-cli pcb drc` + 定点探测复验 | 目视检查教训：探测方法必须用 HitTestFilledArea 而非顶点计数 |
| C5 | 同网桥接用**新增小 zone 对象**而非改既有顶点 | 零风险、可撤销 |
| C6 | 外观类 108 条**豁免并记录**，不逐条修 | silk_over_courtyard/courtyards_overlap 为库级问题，JLC 制造无碍；逐条修需改 40+ 库封装，收益为零 |

## 4. 制造输出决策

- **Gerber**: RS-274X，JLC 预设层集（F/B.Cu、F/B.Mask、F/B.Silk、4 内层、Edge.Cuts）；`--subtract-soldermask` 最小开窗
- **钻孔**: ExCELLon（合并 PTH/NPTH），单位 mm，含 map 文件核对
- **坐标文件**: ASCII 坐标 mm，原点板左下角，含贴片面标识（JLC SMT 用）
- **BOM**: 原理图重出（kicad-cli sch export bom-pcbnew），与既有 bom.csv 差异核对
- **装配图**: 顶/底 PDF（装配层+丝印）
- **打包**: `fab/flowio-p1-jlc.zip`；核对：非 txt 文件数=层文件数+钻孔、无 0 字节、zip ≤ 20MB
- **不做 STEP**：多数封装无 3D 模型（渲染已证实），导出无意义；外壳用尺寸图核对

| 形式 | 底壳 + 顶盖，M3 自攻螺柱×4 |

## 7. 超出本计划范围（需实物/用户操作）

74HCT245/MOS 触发测试（需示波器+板）、传感器到货验证、PID 首跑（需气路）。固件与上位机不在本 spec；需要测试检查单可另立 plan。

## 8. 风险

| 风险 | 缓解 |
|---|---|
| 移动 HD 后新位压到铜 | 移位脚本用与过孔相同的全障碍搜索（Ø3.2+0.5 净空） |
| 桥接 zone 反而制造新的 5V/3V3 交叠 | 桥接矩形逐顶点坐标在 plan 中硬编码并经 zones_intersect DRC 验证 |
| 孤岛检测 API 差异（Outline/Contains） | 任务内先 5 行探针脚本确认 API 再写主逻辑 |
| 删除走线段引发新的未连接 | 只删"定位到的单段"，删后 DRC 差分（条数必须只减不增） |
