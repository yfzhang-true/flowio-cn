## 1. 设计总纲：器件=三接口面实体，连接=三类边图谱

**第一原则**：每个器件 = **三接口面**（气动/电气/机械）+ 参数化几何（datasheet 图纸直推）；
每条连接 = 图谱中一条**带类型的边**（两端点必须存在于器件接口面且口径/类型匹配）。
模块 = 器件+内部边的**组合**，其对外接口面是模块间边的端点。**接口先于几何，几何服务于接口。**

## 3. 连接图谱（connections.json——三类边，机器可校验）

```json
"pneumatic_edges":  [{"from":"P1.OUT","to":"Main.S_wall","tube":{"id":5.0,"od":7.0,"len_mm":60,"bend":2}}, ...],
"electrical_edges": [{"from":"J23.2","to":"P1.MOTOR+","kind":"cable_2p","len_mm":150}, ...],
"mechanical_edges": [{"from":"P1.body","to":"BRK.ring","kind":"silicone_clamp"}, ...]
```
校验器（测试守门）：①每边两端点存在于器件 descriptor 接口面；②口径匹配（嘴径≥管 ID）；
③六动作语义路通（充/吸/排/保/测在图上可达）；④悬空端点=FAIL。
产出即 webapp 渲染数据源（管路/线束 3D 化）+ BRINGUP 接管指南的机器真值。

## 4. 模块接口规约（Module Interface Spec——用户指正的核心，独立文档 docs/module-interface-spec.md）

### 4.1 主模块（功能：控制与分配）
| 面 | 对内 | 对外 |
|----|------|------|
| 气动 | 板/歧管/阀阵（内部免维护） | 8×通道口（→手套）、S 口+V 口（→泵模块）、F 口（→大气）、引压口（→XGZP） |
| 电气 | 板载（阀驱动/传感/主控） | USB-C 电源输入（对外）；**J23 泵电机插座→穿壁电缆（→泵模块）** |
| 机械 | 板铜柱/阀支架/歧管卡座 | S/V 壁面快插板、出线孔 |

### 4.2 泵模块（功能：气源）
| 面 | 对内 | 对外 |
|----|------|------|
| 气动 | 泵双嘴→面板快插 | **双管（充/吸）→主模块 S/V 口** |
| 电气 | 电缆→泵电机端子 | **2P 插头←主模块 J23 引出电缆** |
| 机械 | 硅胶支架×2+底座（自足式） | —（桌面放置，无壳间紧固） |

**模块间连接=3 条边**：气管（充）+气管（吸）+电机电缆（2P）。任何一边缺失=功能降级
（缺气管=无气源；缺电缆=泵不转）——模块接口规约使其成为**显式装配检查项**。

## 6. baseline 研究结论（已检索 + 计划深挖）
- **OSS CAD**：build123d/CadQuery（OCCT 系 Python 参数化建模，STEP/BREP）为标准——
  **FreeCAD 内嵌 OCCT 同核，零新依赖采纳其表达范式**（builder-pattern）；
- **学术**（aminer MCP 已恢复，2026-10-05 检索落地 → docs/research/device-modeling-baseline.md）：
  🎯 Ruzarovsky 2025《Behaviour-Based Digital Twin for Electro-Pneumatic Actuator》
  **已下载全文并精读**（literature/ruzarovsky2025-*.pdf/.txt，res.mdpi.com CDN 绕 Akamai）。
  精读增量结论（详见研究笔记"精读落地"节）：
  ① 三级保真度实证：**"模拟量但无物理"与离散级输出完全相同**——可信度分水岭只在
  气动动态级，支持"默认 L1+L3、气动动态整档 P2、不做半吊子模拟级"；
  ② 式(6) Qn=C·Ath·√Δp（等温标称流量）为 P2 阀/管路建模优先口径（对齐 datasheet 标定）；
  式(4) 腔压 ODE 移植时 Aẋ→dV/dt 腔壁变形项；
  ③ P2 验收集加 **rise-time 误差 + 跟踪误差** 两断言（对齐 BRINGUP 实测）；
  ④ latent phase（指令→压力/运动响应延迟）为独立观测量；⑤ 该文为刚性缸+PLC 域，
  器件级几何不迁移，软体连续体仍归 RA-L 2022 杆理论（次级）。
  另：混合物理+数据建模（Cell Rep. Phys. Sci. 2022）；电磁阀 RUL/状态监测簇
  （P2 医疗安全叙事学术支点）。
- **官方参照**：资源/官方参考/official-3mf（FlowIO 原版模块几何）+ 官方照片（管路走线/
  腕带形态）——集成目视的对照基准；
- **GitHub MCP**：未在当前工具环境；开源库检索已用 WebSearch 完成（结论同上），
  Phase R 可加深（KiCad 3D 库/XGZP 现货 STEP 查证）。

## 7. 验收标准
1. **几何断言**：每器件 port/terminal/mount 的位/向/径 vs datasheet 图纸（参数化断言，带出处）；
2. **连接完备性**：connections.json 每边两端点存在+口径匹配+六动作语义路通+悬空端点=0；
3. **模块接口**：module-interface-spec.md 三类边齐+装配检查项显式；
4. **渲染目视**：泵口朝上/阀引线在位/管路走线 vs 官方参考图+实物照比对通过；
5. **全家桶**：现有全测试保持绿（器件建模不破坏既有契约）。

## 8. 决策点（✅ 2026-10-05 已裁定：全按推荐 A/A/A/A）
- **D1 建模内核 = A**：FreeCAD Part（OCCT 内嵌零依赖）。裁定理由：build123d 与 FreeCAD
  同属 OCCT 内核，可建形状等价——差异只在 API 舒适度 vs 依赖包袱；工程样机阶段稳定优先、
  项目已有 make_manifold/make_pump_module 成熟写法；未来需 STEP 互操作再评估 B。
- **D2 线束渲染深度 = A**：引线桩+2P 壳视觉件（P1.2 深度）。裁定理由：A="诚实的不精确"
  （回答"接没接、接到哪"），B="昂贵的伪精确"（壳内真实布线依赖机械布局定型，P1.2 布局
  还在动，路径会反复作废）；精确线长属机械冻结后阶段。
- **D3 F0520A/C 常开型 = A**：家族留档不进 BOM。裁定理由：NC 架构断电=保压（省电，
  FlowIO 同款已验证）；常开排气阀=断电泄压（对病人更安全）但运行中需持续供电关断——
  医疗级"断电保证泄压"的行业标准答案是**机械式泄压阀**（非电控），留 P2 安全设计
  专门研究笔记，不在 P1.2 顺手带过。
- **D4 线缆/管路路径 = A**：关键弯折点折线。裁定理由：折线每段长度可核算=硅胶管下料
  长度直接喂采购；样条的"自然垂形"依赖重力/管夹数据（现在没有），画出来是伪精确；
  视觉美感属后期打磨。
