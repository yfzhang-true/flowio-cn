\chapter{软体机器人与 FLOWIO-CN 生态位}
\label{ch:intro}

\section{软体驱动的前世今生}
从 PneuNet 驱动器到气压康复手套：软体机器人为什么需要一套"气源+阀+传感"的最小系统。本章将从文献脉络出发，梳理气动软体机器人在康复、抓取与可穿戴方向的三条主线。

\section{MIT FlowIO 与开源生态位}
MIT FlowIO（七常闭阀、板载传感、开源 API）确立了气动软体机器人"标准实验台"的形态。本节分析其七阀拓扑与 FLOWIO-CN 需求的差异，以及继承其 API 语义的价值。

\section{FLOWIO-CN 的差异化定位}
分指压力闭环、数据报表、国产 BOM、开放 API——面向 B2B 康复手套白牌厂商的 \textyen300--500 套件方案，与科研开源套件的生态位差异。

\section{全栈自研的产品思维}
电路（KiCad）+ 结构（FreeCAD/OpenSCAD）+ 软件（ESP-IDF/Python/Web）+ 调试（测试点+逻辑分析仪）四位一体的联合设计流程：本书其余十一章即这条流水线的完整实录。
