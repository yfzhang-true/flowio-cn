# 气压传感器对比：XGZP6897D-C vs TOY0058/BMP180（P1.1 · 2026-10-05）

> 触发：用户推荐 TOY0058（DFRobot Barometric Pressure Sensor，BMP180 模块）并问"气压传感器用哪个更合适"。
> 一手资料：用户供 TOY0058 官方 PDF（已逐页读取）；XGZP6897D-C V1.1 本地在档。

## 结论：**气路压力闭环维持 XGZP6897D-C**；TOY0058/BMP180 解决的是另一个问题（环境大气压/海拔），做不了气路传感。

## 1. 逐项对照（需求：测气路**表压**，工作包络 -50kPa（真空钳位）~ +50kPa+（充气））

| 维度 | XGZP6897D-C（在选） | TOY0058（BMP180 模块） |
|------|--------------------|----------------------|
| **传感原理** | 压阻式**差压/表压**（双倒钩 P1-P2，DPN 正负压型）——对大气即表压，零点内建 | **绝对压**（测环境大气），读数须减环境基准（基准自身温漂 → 误差双份） |
| **量程** | -100~+200kPa 包络工作包络，两侧 ≥2× 裕量 | 绝对压 300~1100hPa（官方特性曲线横轴）：+50kPa 表压 @101.3kPa 环境 = **1513hPa，超上限 37% 直接出程**；-50kPa=513hPa 勉强在程内 |
| **气口** | **双倒钩管直插硅胶管**——就是为气路而生 | **无气口**：BMP180 裸片靠封装小孔感知环境大气，丝印 "Pa" 处即传感器；给小孔套管 = 官方不支持（密封胶损伤/进湿气/死区）——模块上两个黑色接插件是**电气**（供电/级联），不是气动口 |
| **集成形态** | SOIC8，直接回流焊在**我们的主板**上（JLC 贴片） | 面包板评估模块（排针+稳压器+级联座）——是开发工具不是元器件；拆片焊板不现实 |
| **接口/电压** | I2C 0x58 / 2.7~5.5V（5V 轨直挂 ✓） | I2C 0x77 / 5V 模块（裸片 3.3V，1.62~3.6V——挂 5V 轨还得靠模块上稳压器） |
| **精度叙事** | 0.25%FS 级，量程匹配 | 0.12hPa 级是**测海拔**的精度；摊到 ±50kPa 表压全量程 ~0.4% 且零点不稳 |
| **扩 8 通道** | 固定 0x58 → TCA9548A 分道（决策点 3 方案已备） | 同样 0x77 冲突 + 无气口，无从扩起 |

## 2. BMP180/气压计类的正确用法（留档，P2 可选加分项）

环境大气基准/海拔自适应：未来若要输出绝对压或做环境补偿，可加一颗 **BMP390 裸片**
（SMD，非模块）焊在主板边缘感知壳内大气（壳体留通风孔，避开泵振动区）——
与 XGZP 表压读数互校。属锦上添花，不进 P1.1。

## 3. 与 FlowIO 的同源性核对

FlowIO 主模块用的是带气口的压力传感（MPRLS 系，parity-gap §1 记录）——
**带气口表压传感**这条路线与原版同源；TOY0058 这类气象气压计原版也不用。

## 5. 决策点 3 详析：1× 分时 vs 8× 并行（2026-10-05c，用户问）

**1× 分时（歧管测量位，P1.1 推荐）**
- 原理：传感接公共歧管 M；任一通道打开（D_i 开）时 M 压=该通道压。
- 优点：1 只传感（¥20 级）、无 TCA9548A、气路单引出点（泄漏面小）、FlowIO 同构、固件最简。
- 短板：D_i 关断（保压态）时 M 与手套隔离→手套侧压力不可见（漏气检不出）；
  不能多通道同读；单点故障全盲；串行切换需 settle。

**8× 并行（每通道手套侧 + TCA9548A）**
- 测量点在 D_i 手套侧→每只手套永远可见。
- 优点：逐指连续监测（漏气/爆管/过压报警）+ 保压态反馈 + 真多通道并行闭环 +
  传感冗余——B2B 医疗安全/认证卖点。
- 代价：BOM ~¥170（8×¥20+mux）、8×(SOIC8+倒钩让位) PCB 面积、8 引出点装配/泄漏面、
  逐只偏移校准（±0.25%FS 各异，出厂标定表入 NVS）。
- 速度无瓶颈：~1ms/通道转换，100Hz 扫 8 通道富余。

**推荐**：P1.1=1×（FlowIO 同构，最小复杂度）；P2 医疗安全版=8×（安全故事+校准工装）。

## 6. 阀轻量化复核记录（2026-10-05c，用户两度追问）

- JLC/LCSC 官方库**无电磁阀品类**（气动件不入 SMT 目录）→ 阀全走血压计/1688 供应链。
- JF-0530B 查证=**推拉电磁铁**（指纹锁用），非流体阀——轻量档命名雷区实证。
- 0403 血压计小阀行业典型（多源摘要，无一手 datasheet）：0.8~2W、负压 -40~-60kPa、
  ⌀2mm 口径——功率反而比 0520D（0.38W）大，负压额定更薄。
- 0303 级（⌀0.5 孔）：流量裕量 1.4×（vs 0520D ⌀1.2 孔的 8×），接管损后不保熟。
- **结论**：0520D=微型阀效率甜点，P1.1 维持；减重最大杠杆是阀数量（1f α 比 β 少 2 只
  ≈-30g）；轻量档（0403/DFR0866/更小家族）打包 P2 紧凑版调研（届时请用户从 1688 拿规格书）。
