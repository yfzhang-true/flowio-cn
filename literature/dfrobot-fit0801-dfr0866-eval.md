## 1. FIT0801（370 Mini DC Vacuum Pump）——✅ 采纳为正式采购件

官方规格（DFRobot PDF 一手）：
- 工作电压 **1.5~5V**；空载电流 ≤500mA@5V；功率 2.5W@5V；流量 ≥2.2L/min；
  **最大真空 ≥-58kPa**；噪声 <60dB；
- **侧口=吸气、中口=出气**（Introduction 原文）；电机反接=气流方向互换
  （"direction of airflow can be changed by reversing the polarity"）；
  "同时充+放需两只泵"（顺序充放单泵足够）；
- 几何（官方图纸）：总长 58±0.5mm，泵头 ⌀27±0.3×27.3，电机 ⌀24.2；
  **双气嘴 ⌀4.3±0.2**（顶嘴长 10，中嘴长 7），4mm 硅胶管直插过盈 ✓；
- 结论：**这就是 370-pump-FIT0801-spec.md 档案的正式商品**——孪生 PUMP_P_MIN=-58
  本就按它设定。比淘宝套装泵（充吸两用，⌀3.6 嘴）采购链更稳（DFRobot 官方 +
  electromaker 等分销），**P1.1 BOM 采用 FIT0801**，套装泵降为实物对照参考。
- 端口接线：两线直流+低边 MOS 即可，**无需 H 桥**（两口都接管路，反接换向功能用不到；
  留作未来"泵口角色互换"固件可选增强）。

## 2. DFR0866（6V 2-Position 3-Way Air Valve）——❌ 本版否决，保留为低压紧凑版候选

官方规格：6V / 100±10%mA / 60±10%Ω / 0.6W / 喙 ⌀3.0 / **最大压力 40kPa(300mmHg)** /
15g / COM-NO-NC 二位三通（断电 COM↔NC，通电 COM↔NO）/ 体 ~25.1×14×14mm。

三条否决理由（全部可从官方数字直接推出）：
1. **电压方向反了**：6V 额定 > 0520 的 4.5V。挂 5V 轨 = 83% 电压 → 70% 功率/吸力，
   厂商只保证 6V 特性；欠压吸合失败风险恰在背压最高时最大。要正确驱动得加 boost
   **升压**轨——那才是真正增加原理图/PCB 复杂度的方案；
2. **压比不够**：40kPa 天花板 < FIT0801 真空 -58kPa——接进气侧即超额定 45%；
   系统器件压力额定必须包络源极值（0520D -53.3~+300kPa / 0520F ±100kPa 均包络）；
3. **拓扑**：二位三通每通道只能给 {充,排,保} 中的两种，单通道做不全六动作
   （除非 8×3-way+双主阀架构，见 §4 方案 γ 的功率账）。

**用户两个物理论点的裁定（对一半）**：
- "4.5V 增加电路复杂度" ✗：v3 单 5V 轨下 4.5V 阀=**直挂直驱零变换**
  （+11% 过压商家确认合法，驱动电路=任何阀都一样的 MOS+飞轮三件套）。
  反而"电压越低越好"不成立：3V 级阀要从 5V 降压（多一颗 buck=真复杂度），
  6V 级要升压（同理）。**额定电压最贴近轨电压的阀才是零复杂度选择**；
- "电压越大体积质量越大" ✗：绕组窗口由**安匝数（吸合力×行程）**决定，电压经匝数/线径
  自由折算，几乎不占体积。同口径下体积的主因是**压比**——DFR0866（6V）比 0520F（4.5V）
  小 2/3，正因为它 40kPa vs ±100kPa。反例就在用户自己提的候选里。
- DFR0866 保留路径：若未来出"紧凑低压版"（系统压比 ≤40kPa，血压计域），
  15g/0.6W/3-way 是首选；本康复手套版压比包络需求（≥±53kPa）不满足。

## 3. FIT0801 入手引出的架构缺口（比选型更重要）

FIT0801 双口（吸/出分立）+ FlowIO 六动作（含 **Vacuum**）对照现架构：
**方案 α（现案：8×0520D 2/2 通道阀 + 1×0520F 排气总阀）做不了单通道真空**——
通道口只与"充气歧管"连接，没有到泵吸气口的路径。kit 套装的"吸气阀"是全局一路，
FlowIO 语义里 Vacuum 是每通道动作（parity 表已承诺）。

## 4. 阀架构三方案（新决策点 1f）

**方案 β（推荐）：公共歧管 + 11×0520D 单型号**
- 拓扑：一条公共歧管 M（8 通道口+3 主阀口）。每通道 1×0520D（D_i：通道↔M）；
  3 主阀全用 0520D：S（泵出气口↔M，充气总闸）、V（泵吸气口↔M，真空总闸）、
  F（M↔大气，排气总闸）；FIT0801 双口分别接 S/V；
- 六动作全通：充=S+i+泵 / 保=全关（M 密封）/ 排=F+i / **吸=V+i+泵（每通道真空 ✓）** /
  测=XGZP / 变速=Q 泵 PWM；
- 附赠能力：V 开+S 开=泵把 B 通道气"搬"进 A 通道（单泵实现"同时充放"的等效语义，
  且 B 的排气不浪费直接喂 A——FIT0801 手册说这需要两泵，阀网络做到单泵）；
- 功率：11×94.5mA(5V)=1.04A + 泵 ~0.5A ≈ **1.55A 稳态 / 2.05A 泵启动** < 3A ✓；
- BOM：**阀单一型号 0520D ×11**；歧管从两条变一条（8+3 口，结构更简）；
- 驱动：12 路（Q3-Q10 通道 + Q11 S + Q12 V + Q13 F + Q14 泵）；
- 固件两条新约束：①泵只在 S/V 开启时运转（防死头空转）；②系统真空钳位 ≥-50kPa
  （0520D 真空额定 -53.3 < 泵 -58，孪生 VALVE_P_MIN_KPA=-53.3 已有）。
