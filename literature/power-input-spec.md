# 电源输入口调研（P1.1 v3 · 2026-10-05）

> 触发：v3 单 5V/3A 电源树需输入口承载 ~2.1A 峰值。核查发现**现板 DC005 额定仅 500mA——v3 新增第 6 项必修缺陷**。

## 1. ⛔ 现板 J1：C431533（SHOU HAN DC005）不可承载执行器轨

JLC 属性（一手）：**Current Rating 500mA** / Voltage 12V / Body Height 10.9mm /
13.6×9.9mm / 内孔 ⌀2.0 外触 ⌀6.3 / Right Angle Plugin。
- 500mA < 2.1A 峰值（8×0520D 0.75A + 0520F 0.36A + 泵启动 1A）→ **必须换型**。
- 本地 PDF `资源/器件规格书/数据手册/C431533_…_WJ1966441.PDF` 为纯机械图，无电气额定文字——额定以 JLC 属性为准。
- 连带影响：J1 槽带高度 case_geom（现按 10.9+0.2 收 11.1）与新 footprint 同步重算（换 DC-044 反而**收窄到 7.4**）。
