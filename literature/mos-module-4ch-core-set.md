## 2. 接口与接线（页4 应用电路）

```
输入侧（每路独立）            输出侧（与输入完全隔离）
ESP32 GPIO ──1K── PWM1        电源+ ── 12V+（阀）/5V+（泵）
ESP32 GND ─────── GND1        电源- ── 12V-/5V-
                               OUT1+ ── 阀1 线圈一端
                               OUT1- ── 阀1 线圈另一端
（PWM2..4 / GND2..4 同理）     （OUT2..4 同理，每路独立开关）
```

- 负载跨接在 OUTn+ 与 OUTn- 之间（隔离输出开关，**不是**共地低边拓扑——旧装配指南按低边写的接线方式作废）。
- 输入端 GND 必须接 MCU 的 GND（页6）；输出侧电源地与输入地因 2000V 隔离可不共地（但本项目全系统共地也无害）。

## 3. ⚠️ 3.3V 直连低于输入规格下限（到货必测项）

页3/页6 明确输入信号范围 **3.6~20V**；ESP32 GPIO 高电平仅 3.3V，低于下限。光耦输入为"限流电阻+LED"结构，3.3V 时 LED 电流偏小，可能仍触发但**超出规格、裕量不足**（温度/批次敏感）。

决策（双保险，见装配指南 §MOS）：
- **方案 A（推荐）**：5V ── 上拉电阻 ── 模块 PWM 输入，ESP32 经 AO3400（BOM 备料）开漏拉低控制，栅极串 1K——即一级分立电平转换，输入侧变成 0/5V PWM，完全入规格。
- **方案 B（实测兜底）**：到货后先做"3.3V+1K 直连触发可靠性"门禁测试（连续 60s 1kHz PWM 无失触发）；不达标立即上方案 A。

## 4. 与原假设的差异清单（本次修正的"错误"）

| 原假设（BOM/装配指南） | 实际（本资料） | 处置 |
|---|---|---|
| 8 路低边 MOS 模块 | 4 路隔离输出开关 | 需 2 块；接线表重写 |
| 3.3V 可直接触发 | 输入下限 3.6V | 电平转换方案 A + 到货实测门禁 |
| 触发方式存疑（风险项） | 高电平 PWM 有效，0~20kHz | HAL 无需改极性；风险关闭 |
| 低边拓扑（阀另一端接 12V+） | 每路 OUT± 独立隔离输出 | 阀线圈跨接 OUTn± |
| PWM 能力待证 | 明示 PWM 输入 | 阀保持降占空比实验合法 |

## 5. 数字孪生影响评估

- 孪生物理层**无需改动**：光耦+MOS 开关延迟（µs 级）远小于 50ms 物理步；duty→流量缩放模型因 PWM 0~20kHz 明示支持而继续有效。
- HAL 固件**逻辑无需改动**（高电平有效与现有 LEDC 一致），仅更新注释与装配文档。
- 硬件层新增到货门禁：3.3V 直连触发可靠性实测（装配指南 §测试步骤）。
