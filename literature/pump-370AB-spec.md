# 370 微型气泵 A/B 细分调研（P1.1 · 2026-10-05）

> 任务来源：用户"注意有两种370细分型号，370-A或者370-B"+"必须找到所有新增器件的数据手册，获取准确一手信息"。

## 1. A/B 语义（网络多源交叉，非厂商一手）

| 型号 | 调校取向 | 典型应用 | 同族配阀 |
|------|---------|---------|---------|
| **370-A** | 正压充气型 | 电子血压计（袖带充气） | 0520A |
| **370-B** | 负压抽气型（充吸两用） | 电动吸奶器（吸引+可充气） | 0520B |

- 两者为同尺寸（370 电机级 ⌀24mm）隔膜泵的两个出厂调校版本，选型看正压输出 vs 负压真空度。
- 370-B @ 威力兹（fspump.cn，2017 存档快照）：额定电压 DC6.0V（<500mA）/ DC12V（<280mA）/ DC24V（<100mA）。
- 通用常识校验：正压泵=排气口高于大气压，负压泵=进气口低于大气压；隔膜式存在充吸两用型。
- 来源：上海霍亚流体 hnx-pump.com 选型文、东莞宗旨电子 gdaim.com、佛山威力兹 fspump.cn（**站点已停摆**，阿里云 ipvisit_stop）、新为诚 wcjx.net。

## 2. 用户实泵（淘宝套装散件，一手测量 + 图片直读）

### 2.1 散件.pdf（图片型 → pypdf 抽内嵌图 9 页全读，存 extract/散件/）
- 泵名：**"370直流充吸两用真空泵"，不分正负极**——单泵双口：顶部充气口 + 侧/顶吸气口，
  充=排气口出气，吸=进气口吸气 → **一只泵即覆盖 FlowIO 正压+负压双语义，无需双泵**。
- 配套：0520F 型两位三通阀×2（充气阀+吸气阀，断电 1↔2 通/通电 1↔3 通——与已定案 0520F 一致）。
- PWM 电子开关：3V~5V 工作电压，最大 2A，直通输出。
- **卖家供电推荐："电源推荐用 5V2a~5V3a 手机充电头 或 电脑USB3.0"** → 与 v3 单 5V 电源树互证。
- 附 Arduino/ESP8266/ESP32 示例码（50Hz PWM 14bit 控三路开关）——仅套件玩法，与本项目固件无关。

## 4. 设计结论（回写 spec v3）

> **2026-10-05b 更新**：用户从 electromaker 渠道取得 **FIT0801 官方 DFRobot PDF**——
> 本档案 §2 的套装泵与 FIT0801 同族同规格（-58kPa/2.2LPM/1.5~5V）。**P1.1 BOM 正式
> 采购件定为 FIT0801**（官方链路稳定，⌀4.3 双嘴→4mm 管与歧管计划一致；端口语义：
> 侧口=吸气、中口=出气，反接换向功能两口都接管路后用不到）。套装泵降为实物对照。
> 详见 `dfrobot-fit0801-dfr0866-eval.md`。

1. 决策点 1e 简化：**单只"370 直流充吸两用真空泵"即覆盖充/吸双向**（FlowIO 泵模块等价物），
   无需 A+B 双泵；BOM 按"充吸两用型"下单，A/B 商家命名到单前请卖家确认即可。
2. 驱动：Q14（AO3400A）+ SS14 飞轮 + PWM 调速；启动冲击 ~1A（FIT0801 同族档案）已计入 5V/3A 轨预算。
3. 有刷不宜连续运转 → 固件间歇策略（孪生已有 pump duty 模型，PUMP_P_MIN_KPA=-58 保守成立）。
4. 减振软垫舱 + 软管接歧管（T6）；双嘴 ⌀4.3（FIT0801）→ 4mm 管；阀侧 Φ3.2 → 3mm 管；歧管内变径。
