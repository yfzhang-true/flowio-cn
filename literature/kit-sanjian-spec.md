> 用途：P0 压力源级（泵+两只三通阀+三只舵机开关）+ 测试气囊 + 管路

## 1. 清单确认（p9 产品清单，与 BOM 记录一致）

白色主控盒×1（TYPE-C 5V 供电口）、370 充吸两用泵×1、两位三通电磁阀×2、
舵机式 PWM 电子开关×3、波浪纹气球×3、硅胶管 4×6mm×2m、三通/变径接头若干。
散件不含控制板/电池/遥控（我们不要它的 ESP8266 板）。

## 2. 内部布局（p3 爆炸图）

主控盒内：泵 + 充气三通阀 + 吸气三通阀 + 泵开关 + 充气阀开关 + 吸气阀开关
——**1 泵 + 2 阀 + 3 舵机开关**，与 HAL 映射（pump/inlet/vent 各一只舵机开关）一致。

## 3. 舵机式 PWM 电子开关（p6，逐字）

- **工作电压 3-5V，最大电流 2A，直通型（输入多少 V 输出多少 V）**
- **180°=接通 / 0°=关断**；**50Hz 舵机 PWM 信号**
- 线序：红=VCC、黑=GND、白=信号
- 与固件 HAL 对应：RMT 50Hz，脉宽 500µs=0°(关)、2500µs=180°(开) ✓ 语义已对齐
- ⚠️ 2A 上限：泵启动峰值 ~1A 内 ✓；**只有通/断两态，不支持 PWM 调速/保持降压**（这正是必须外加 MOS 模块的原因，BOM 依据成立）

## 4. 370 泵（p7）

DC 5V、充吸两用、红=VCC 黑=GND。完整参数以 FIT0801 规格书为准
（`370-pump-FIT0801-spec.md`：≥-58kPa、2.2L/min、嘴 ⌀4.3±0.2mm）。

## 6. 气路拓扑（p5）

泵充气口→充气三通阀→汇流；泵吸气口→吸气三通阀→汇流；三通对外孔通大气；
硅胶管 **4×6mm**（内径 4mm）——与装配指南管路设计一致。
