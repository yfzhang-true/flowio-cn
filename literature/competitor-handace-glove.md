# 竞品参照：HANDACE 汉戴斯 康复机器人手套（2026-10-05）

> 汉戴斯.pdf（18 页 listing 图）经抽图目视识别：**不是配件供应商，是竞品整机**——气动手部康复锻炼器源头工厂（OEM/ODM，私模专利，认证齐全）。

## 产品形态（p0 主图 + 后续页为 listing 细节）

- 一体式气动机器人手套：五指分段式气囊指套 + 魔术贴绑带固定，独立**圆盘形泵控主机**（数码管显示 + 按键）。
- 主机与手套间一根多芯气管缆；配 5V USB 线充电（锂电路线）。
- 卖点关键词：锻炼手指灵活度/居家练习/强劲动力。

## 对 FLOWIO-CN 的意义（分析，非器件）

1. **市场验证**：该品类在国内已是成熟量产货（源头工厂直供），印证 B2B 康复手套厂商的采购场景真实存在。
2. **架构差异**：竞品=主机+手套分离、单一泵阀组顺序控制五指；FLOWIO-CN=模块化气动平台、
   8 独立通道+压力闭环，能力上限显著更高（这正是 B2B 差异化卖点）。
3. **可借鉴**：绑带式指套佩戴结构、主机圆盘形态的适手性；listing 的"锻炼灵活度/居家"话术。
