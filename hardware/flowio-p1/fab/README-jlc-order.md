# FLOWIO-P1.1 嘉立创全代工下单指南（PCBA 标准版 + 3D 打印代打）

> T5 重校 2026-10-05：板 100×80 布线终态 / BOM 39 行 146 件 / THT 仅 7 件（12× XH-2P 已改 SMD 卧贴）。

目标交付形态：**用户零手工焊**。JLC 完成 PCB 制造 + 139 件 SMT 贴焊 + 7 件 THT 代插代焊；
上下外壳 3D 代打。收货后只需拧 M3 螺丝装配 + 插线即用。

| 文件 | 用途 |

## 1. PCBA 下单步骤（jlc.com → PCB 制造 → 勾选"PCB 组装"）

1. **上传 Gerber** `flowio-p1-jlc.zip`，参数照 `README-fab.md`：
   4 层 / **100×80mm** / 板厚 1.6 / 最小线宽 0.2/0.2 / 过孔覆盖（阻焊塞孔）/ 白色丝印 /
   无需工艺边 / **表面处理选 ENIG**（XH 端子与塞孔可焊性）。
2. **组装类型选「标准版」**——硬约束，两个理由：
   - U1 `ESP32-S3-WROOM-1-N16R8`（C2913202）库属性为 **standard-only**，经济版无法上贴（已实测查询确认）；
   - J5-J9/J18/J19 共 **7 只 XH-4P 插件（THT）**需要标准版代插代焊——这是"零手工焊"的关键。
   （P1.1 起 J10-J17/J20-J23 共 **12 只 XH-2P 已是 SMD 卧贴**（C7429671），回流焊即可，不再计入 THT。）
3. 数量选 **5**（打样），上传 BOM `flowio-p1-bom-jlc.csv` 与 CPL `flowio-p1-pos-jlc.csv`。
4. **确认 BOM 解析**：39 行全部匹配出物料、无"无物料/缺码"行；所有上贴器件全部勾选
   （U6 XGZP6897D 为淘宝件 CFSensor，**不上贴自焊**；TP1-TP13 测试点与 HA-HD 安装孔为裸铜/板件孔不入 BOM，正常）。
5. **确认 CPL 解析**：位号共 **147 个、全部 top 面**。PosY 为负是 KiCad 向下 y 轴的导出方向，
   JLC 接受。核对法：任取 3 行对照 `assembly-top.pdf`——U1 应在板左上、J10-J17 应在板底边一排、
   J20-J23 应在板右边缘一列、J2 应在板右上角。
6. **下单留言栏抄录**（工艺备注，原文）：
   - 本板 13 处 via-in-pad（J20.1/J21.1/J22.1/J23.1/C2.1/U3.2/U5.2/U4.3/R4.1/LED1.1/R16.1/C9.1/R29.2），
     需 IPC-4761 Type VII（树脂塞孔+电镀封帽），否则焊膏流入孔桶造成虚焊；
   - 最小过孔孔距 0.274mm（壁距，≥ 贵司 0.2 限值；板内 DRC 已清零超距对）；
   - 表面处理 ENIG（XH 插件可焊性）。
7. 付款前看预览拼版图：顶面 139 SMT + 7 插件全部有位号标注，即正确。

## 2. 3D 打印下单（jlc.com → 3D 打印）

1. 分别上传 `hardware/flowio-p1/enclosure/case-top.stl` 与 `case-bottom.stl`。
2. 材料两档任选：
   - **PLA（默认推荐）**：结构强度够、最便宜；
   - **MJF 尼龙 PA12（若在列，进阶）**：强度/韧性/耐温最佳，适合长期按压的卡扣与螺柱，价高；
   - 树脂：表面细但脆，不建议用于承载外壳（仅外观件可用）。
3. 壁厚自检已过（≥1.2mm，水密网格已验证），无需再加厚。
4. **摆放方向**：上壳通风栅所在面**朝上平放**可减少支撑。JLC 默认可能自动转向——
   选"摆件需人工确认"，或下单备注"保持模型原始方向"；层高 0.1-0.2mm 均可。

## 4. 不上贴 / 自购说明

- **JLC 不上贴：U6**（XGZP6897D 气压传感器，淘宝件无 LCSC 码）——到货后手工补焊
  （SO-8 手焊难度低，或与外壳装配同工序完成）；其余 145 件全部由 JLC 供料上贴/代插。
- 测试点 TP1-TP13 为裸铜焊盘、安装孔 HA-HD 为板件孔，均无实物器件、不入 BOM（正常）。
- 需自备的只是**使用耗材**：XH2.54-4P 对线、USB-C 数据线、12V DC 适配器、
  气路快插接头与气管、M3×6 螺丝×4（装壳）。
